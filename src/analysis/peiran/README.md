## 三、逻辑核心：纳音身命法

### 1. 年命为身

- **年柱纳音 = 身 / 本命 / 先天禀赋 / 祖业根基**
- 月柱纳音 = 父母、少年
- 日柱纳音 = 自身、配偶、中年
- 时柱纳音 = 子女、晚年
- 胎元纳音 = 受胎环境、长辈缘分

### 2. 四柱纳音生克链

按年 → 月 → 日 → 时判断相邻纳音关系：

| 方向 | 古法口径 | 断语 |
| --- | --- | --- |
| 时生日、日生月、月生年 | 下生上 | 进发、大富大贵 |
| 年生月、月生日、日生时 | 上生下 | 泄气、奔波、耗损、贫贱 |
| 年克月、月克日、日克时 | 上克下 | 尊制卑、为顺、多富贵 |
| 时克日、日克月、月克年 | 下克上 | 犯上、家门破败、起伏、伤长辈 |
| 三组关系不一致 | 生克交错 | 逐柱细看，吉凶随刑冲 |

### 3. 身强弱

年命纳音得分从 50 起算：

| 信号 | 分值 |
| --- | --- |
| 月/日/时纳音生年命 | +12 / 柱 |
| 年命克月/日/时纳音 | +7 / 柱 |
| 年命生月/日/时纳音 | −7 / 柱 |
| 月/日/时纳音克年命 | −14 / 柱 |
| 同气 | −1 / 柱 |
| 胎元生年命 | +5 |
| 胎元克年命 | −7 |
| 年命纳音在月令旺/相/休/囚/死 | +8 / +4 / −2 / −4 / −6 |

- ≥ 62：身强
- 38–61：中和
- ≤ 38：身弱

### 4. 刑冲、三合、纯旺、胎元

- **刑冲害**：年支与月/日/时支的六冲、六害、三刑、自刑。
- **三合局**：申子辰水、亥卯未木、寅午戌火、巳酉丑金；合化五行与年命同气主富贵，生年命主进发，泄年命主耗损，克年命主凶。
- **纯旺**：四柱纳音同一五行；当令为纯旺太过，不当令为纯而不旺，均需制化。
- **胎元**：月干进一位、月支进三位；克年命主长辈缘薄，生年命主长辈有助。

### 5. 日柱纳音性情

日柱纳音决定精神、气质、本性的取象，例如：

- 海中金：深沉难测，城府较深
- 炉中火：热情奔放，积极外显
- 大林木：能团结人，有组织力
- 涧下水：温文尔雅，清静自然
- 大驿土：稳重踏实，走四方

### 6. 盲派纳音长生

以**日柱纳音**起长生，顺排十二运：

| 日柱纳音五行 | 长生位 |
| --- | --- |
| 水 | 申 |
| 木 | 亥 |
| 金 | 辰 |
| 火 | 卯 |
| 土 | 午 |

断运忌字：

- 木见绝
- 金怕临官、衰
- 水病、绝
- 火沐浴
- 土养、病

四绝：

- 寅酉金绝：道路伤灾
- 卯申木绝：车马、盗贼
- 午亥水绝：口舌官司
- 子巳火绝：体囚受绝

> 此为盲派口径，与正五行长生（木亥、火寅、金巳、水申、土午/申）不同。**不得混用。**

## 四、大运 / 流年纳音吉凶评分（v1.1）

### 1. 评分信号

| 信号 | 取值 | 分值 |
| --- | --- | --- |
| 大运/流年纳音生年命 | 受生 | **+2.0** |
| 年命克大运/流年纳音 | 制，劳而有成 | **+1.0** |
| 同气 / 比和 | 合作与竞争并存 | **0** |
| 年命生大运/流年纳音 | 泄气 | **−1.5** |
| 大运/流年纳音克年命 | 受克 | **−2.0** |
| 日柱纳音行盲派忌字 | 绝/临官/衰/病/沐浴/养等 | **−2.0** |
| 日柱纳音行长生/冠带/帝旺 | 得气 | **+1.5** |
| 日柱纳音行临官（非忌字时） | 得气 | **+1.0** |
| 日柱纳音行死/墓/绝（非忌字时） | 失气 | **−1.0** |
| 其他十二运 | 平 | **0** |

### 2. 归档规则

```
总分 = 年命关系分 + 日柱纳音十二运分
总分 ≥ +1.5 → 吉
总分 ≤ −1.5 → 凶
其余 → 平
```

### 3. 为什么要改成评分制

旧版是“单一信号一票否决”：只要犯盲派忌字就直接判凶，或只要受生就直接判吉。会出现：

- 大运生年命（+2）但行忌字（−2）→ 旧版直接凶，实际应为平；
- 大运克年命（−2）但行长生气（+1.5）→ 旧版直接凶，实际应为平。

评分制把两个体系（年命生克、日柱十二运）分开计分，再按总分归档，避免互相覆盖。每条结果都带 `fortuneReasons`，可在表格“评分”列悬停查看明细。

> 当前权重是 **v1.1 初始值**，后续用案例回测调整；调整只改 `evaluateFortune` 中的权重与阈值。

## 五、数据书命名与结构

数据书全名：**《沛然堂纳音身命数据书》**（Peiran Nayin Codex）

文件：`src/analysis/peiran/nayinData.ts`

### 1. 条目结构

```ts
interface NayinEntry {
  name: string;              // 纳音名，如「海中金」
  element: ElementKey;       // 五行大类
  yinYang: 'yang' | 'yin';   // 阳纳音 / 阴纳音
  ganzhi: [string, string];  // 对应两组干支，如 ['甲子', '乙丑']
  image: string;             // 三命通会·论纳音取象
  likes: string;             // 喜
  dislikes: string;          // 忌
  personality?: string;      // 日柱纳音性情
}
```

### 2. 数据分层

| 数据 | 变量 | 用途 |
| --- | --- | --- |
| 六十甲子纳音 | `NAYIN_BY_GANZHI` | 排四柱纳音、大运/流年纳音 |
| 三十组纳音条目 | `NAYIN_ENTRIES` | 取象、喜忌、性情 |
| 盲派长生起点 | `NAYIN_CHANG_SHENG_START` | 大运/流年十二运 |
| 断运忌字 | `NAYIN_BAD_STAGES` | 吉凶评分 |
| 四绝 | `NAYIN_SI_JUE` | 伤灾提示（数据保留，当前不展示） |
| 象格 | `NAYIN_PATTERNS` | 兰台妙选格局 |

### 3. 扩展数据的原则

1. 只改 `nayinData.ts`，不在 `nayinAnalyzer.ts` 里硬编码新的纳音名。
2. 新增象格必须写清：名称、条件、断语、出处。
3. 新增盲派口诀必须标注“盲派口径”，不得与正五行长生混写。
4. 数据书版本号写在文件头；规则变更同步更新本 README。

## 八、边界与口径

1. 沛然堂线不写回阴阳线的用忌 marks、评分、格局、富贵。
2. 纳音长生采用盲派口径，不采用正五行长生。
3. 流年纳音可用；流月、流日一般不用纳音。
4. 象格只作取象，不因未入格否定命局。
5. 后续可扩展：纳音合婚、纳音神煞、完整六十象格、纳音与正五行对照通道。

- 五维模块暂不接入客户展示层；先决定“纯纳音”还是“纳音取象 + 正五行底盘”的路线。
