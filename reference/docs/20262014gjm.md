卡片名：八字太极分层
年月太极：命局规定层，决定格局、五行强弱、命局需求。
日时太极：被规定层，看日主能否回应年月需求，并呈现最终结果。
年干：吉凶和内容的根本来源，本身不单独断吉凶。
月令：规定五行强弱，决定年干吉凶是否成立。
年支：年干的落实处，决定年干能否落地。
月干：由五虎遁推得，是年干在月上的状态说明。
时柱：由五鼠遁推得，是日功的最终结果。
2. 再建一张“判断规则卡”
这张卡专门放断语和逻辑链。
卡片名：年月太极吉凶判断
年干必须经月令检验后，才能断吉凶。
年干吉，月令助之：根本有吉。
年干吉，但落实不好：有吉根，但起伏大。
年干凶，被月令制约：忌神受制，反有得处。
年干凶，又得落实：忌神有力，应凶更明显。
月干由五虎遁决定，说明年干在月上的状态。
时柱由五鼠遁决定，说明日主最终结果。
3. 再存一张“流程卡”
这张卡用于实际看盘时按步骤走。
卡片名：八字读盘顺序
先看年月太极：命局大环境是什么。
看年干在月令中的状态：得令、失令、受制。
看年支是否落实年干：吉根能否落地，凶根是否被制。
看日主能否承担年月之气：日主需要什么来平衡。
看时柱是否达成日功：结果是否呼应年月需求。
4. 配一张“链路图卡”
可以单独存成一张图或流程图卡片。
卡片名：八字整体链路
年 → 月 → 日 → 时
年提供根本 → 月规定强弱 → 日承担需求 → 时呈现结果
或者更细一点：
年 → 月：产生吉凶
月 → 日时：产生需求
日时 → 年月：看是否回应、能否达成

6. 最后留一个“案例卡位”
每学完一个八字，就按同一模板复盘：
卡片名：案例复盘模板
命局：年、月、日、时
年月太极：年干是什么？月令如何规定？
年干吉凶：是否得令？是否受制？
年支落实：年干是否落地？
日主需求：日主需要什么？
