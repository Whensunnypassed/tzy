# 方案 B · 太极二气配比与土纳阴纳阳 · 设计与标定

> 状态：**已实施（默认 dormant）**。机制已进入引擎核心，逐月灰度开关默认 `binary`（不改动现行用忌/评分），待命例达标后逐月切 `taiji`。
> 实施记录：`baziData.ts` 新增 `TAI_JI_QI_PAIRS` / `TAI_JI_MODEL_PARAMS` / `YONG_JI_MODE`；`baziAnalyzer.ts` 新增纯函数 `computeTaiJiQi` 与 `resolveYongJiMode`，`analyzeYongJi` 的大方向判据来源改由 `YONG_JI_MODE` 控制（签名不变）；`BaZiAnalyzerPage.tsx` 04 用神忌神区新增「太极二气配比」旁证块。
> **激活前置条件**：`analyzeMingJuPattern` 等模块仍直接读取 `monthQi.usageDirection`——若仅切 `analyzeYongJi` 会产生「全链路不同源」矛盾，故激活某月前须先将这些模块统一到同一判据来源。
> 目的：把现行「月令元素级二分定用忌」升级为「以月令太极二气存量配比动态定用忌」，并把土的「纳阴纳阳」由燥湿硬分类改为可标定折算，并入二气力量。
> 约束：不动四柱徽章 / 大运流年评分链路的对外接口；通过 CFG version 开关支持一键回退（可进化契约）。

## 一、为什么要改（现行口径的局限）

现行 `analyzeYongJi`（`src/utils/baziAnalyzer.ts` L322–L409）的用忌大方向由**静态字段** `monthQi.usageDirection` 决定（L327–L333）：

- `usageDirection === 'yin'` → `usefulElements = ['metal','water']`、`tabooElements = ['wood','fire']`
- 否则 → `usefulElements = ['fire','wood']`、`tabooElements = ['metal','water']`

`usageDirection` 取自 `src/data/baziData.ts` 的 `MOCK_MONTH_QI`（L778 起，字段定义 L35–L43），是**逐月固化**的「用阴 / 用阳」，与柱中实际组合无关。

《十二月份取用》原文对此明确反对（L14）：

> 「判断用阴用阳是一个误区，用阴或用阳，就是傻瓜式的模版套用。」
> 「我的方法就是**弱化用阴用阳的概念，看丙癸太极**，其他元素只是扶抑丙癸的元素而已，以此来判断。」（L39）

这就是方案 B 的理论依据：**月令的二气太极（春=丙癸 / 秋=丁壬 / 夏=庚金与火 / 冬=火与水）才是用忌的真实锚点**，其余元素只是扶抑这两股气的辅助。现行「整类二分」恰好是原文所批评的「模版套用」。

同时，现行 `calculateYinYangBalance`（L1789–L1823）已把土按燥湿归入 `yang`/`yin`（`EARTH_YANG_GANZHI`），但归法是**硬分类**，未按「土无阴阳、纳阴纳阳、随柱中寒热而折算」的原文语义量化（《五行取象逻辑》：「土无阴阳偏性……接收木火能量（纳阳）、承载金水阴气（纳阴）」）。

## 二、理论依据要点（《十二月份取用》）

| 月组 | 太极二气 | 关键判据 | 原文 |
|---|---|---|---|
| 寅卯（春温） | **丙火（富基）· 癸水（贵基）** | 木得火肯定→成温；见水即体阴用阳；见金须**落实年支**才破格 | L13、L15、L18、L35 |
| 辰 | 温已成、阴阳不明 | 关键在**救癸水**：木克土救水（须木得水润）／金泄土生水 | L59–L68 |
| 巳午未（夏热） | **火（阳）· 庚金（阴）** | 首用庚金；**水木须齐见**（孤水被土克、孤木生火皆败）；阴土（戌丑）晦火存金 | L79–L86、L103–L115、L118+ |
| 申酉（秋凉） | **丁火（余热）· 壬水（成凉）** | 先辨**余热局／成凉局**，两局取用相反 | L13 |
| 戌 | 阴气已重 | 甲木为第一用神 | 见《04_古法辑要》 |
| 亥子丑（冬寒） | **丙丁火（阳）· 壬癸水（阴）** | 止寒为要：子月辰未阳土止寒第一、丙丁火第二；丑月己土止寒为贵根 | 见《十二月份取用》冬三月 |

原文对春秋两季留了**可形式化的常规论法**（不作模糊处理）：

- 寅月：木得火肯定 → 甲木少阳成阳、且不被金水阴气否定 → 成温为体阳用阴；否则体阴用阳（L18）。
- 卯月：只要见水，即为体阴用阳；见金要看金是否落实在年支，落实则不以成温论（L35）。

## 三、模型设计

### 3.1 太极二气对表（CFG，按月经 CFG 定义）

新增常量（`src/data/baziData.ts`，带 `version`/`source`/`principle`）：

```
TAI_JI_QI_PAIRS = {
  version: '1.0.0',
  source: '《十二月份取用》',
  months: {
    寅: { yang: ['fire'], yin: ['water'], mode: 'chun' },
    卯: { yang: ['fire'], yin: ['water'], mode: 'chun' },
    辰: { yang: ['fire'], yin: ['water'], mode: 'rescueYin' },   // 救癸水
    巳: { yang: ['fire'], yin: ['metal'], mode: 'xia' },         // 首用庚金
    午: { yang: ['fire'], yin: ['metal'], mode: 'xia' },
    未: { yang: ['fire'], yin: ['metal'], mode: 'xia' },
    申: { yang: ['fire'], yin: ['water'], mode: 'qiu' },         // 丁壬，先辨局
    酉: { yang: ['fire'], yin: ['water'], mode: 'qiu' },
    戌: { yang: ['wood'], yin: ['water'], mode: 'rescueYang' },  // 甲木第一用神
    亥: { yang: ['fire'], yin: ['water'], mode: 'dong' },
    子: { yang: ['fire'], yin: ['water'], mode: 'dong' },
    丑: { yang: ['fire'], yin: ['water'], mode: 'dong' },
  }
}
```

### 3.2 二气存量公式

对每一柱 `i`（年/月/日/时），沿用既有柱位权重 `PILLAR_WEIGHTS`（`baziAnalyzer.ts` L1274–L1279）：年 `1.0/1.5`、月 `1.2/2.5`、日 `1.5/1.8`、时 `0.8/1.2`。

对某一「太极气」（代表元素集合 E）：

```
气存量(S) = Σ_{柱 i} Σ_{该柱出现的干支/藏干 g，且 element(g) ∈ E}
              w(i) × s(g) × k(土)

其中：
  w(i)  = 柱位权重（天干取 stem、地支取 branch，藏干按 (0.5 − 序×0.15) 递减，沿用 L1769–L1775 现行系数）
  s(g)  = 该干支在月令的十二长生强度，由 SHI_ER_CHANG_SHENG_CYCLE 环序 CFG 归一化：
          s = (power + 20) / 44        // power∈[−20,24] → s∈[0,1]
          （月令本气所在支及其藏干 s 恒取 1.0，体现「月令为权」）
  k(土) = 土的折算系数（见 3.4）
```

> 归一化区间 `[−20,24]` 取自本轮已入库的 `SHI_ER_CHANG_SHENG_CYCLE.stages`（绝=−20 … 帝旺=24），与 `analyzeChangShengRing` 同源。

### 3.3 用忌判定（替代 `usageDirection` 二分）

```
balance = 气存量(阳) − 气存量(阴)
ratio   = balance / (气存量(阳) + 气存量(阴))

判据（建议初值，可由 CFG 调整）：
  ratio ≥ +θ  → 阳气有余（阳过）
  ratio ≤ −θ  → 阴气有余（阴过）
  |ratio| < θ → 二气均衡（太极完整）
```

- **阳过（夏型）**：用阴方（庚金为首用、水木齐见为辅），忌阳（火、燥土）。
- **阴过（冬型）**：用阳方（丙丁火、阳土止寒），忌阴（金水）。
- **均衡（太极完整）**：以中性为主，仅对「被否定 / 被克最重」的一方标记为待扶（useful），对其压制方标记 taboo——即原文「丙癸两不伤则富贵双全」的量化落点。
- **春秋（`mode: chun` / `qiu`）**：直接比较该季太极二气（丙癸 / 丁壬）的存量，**不足且受损者**判为 useful，**有余而压制者**判为 taboo；并保留原文「见水即体阴用阳」「见金须落实年支」两条硬条件（落实年支判定读 `chart.year.branch`）。
- **`mode: rescueYin`（辰）/ `rescueYang`（戌）**：以「救被压方」为主轴——辰月救癸水（木/金泄土生水为 useful，戊土重为 taboo）；戌月扶甲木（甲为 useful，辛金/水为 taboo）。
- **条件字锚点保留**：既有 `MONTH_ELEMENT_XIJI_OVERRIDES`（午月水=neutral，L298–L301）与 `MONTH_STEM_XIJI_OVERRIDES`（辰月甲=useful，L304–L307）机制原样保留，仍以逐字资料库 `ZHUZI_XIJI_REF`（`monthCharMark`，L358–L372）为**唯一干支级真源**，新模型仅在资料库缺字时兜底（与现行 L358 注释一致）。

> 关键：新模型**只改变大方向的判据来源**，`useful/taboo/neutral` 三分与下游「marks → ±weight」评分链路（L1332–L1340）保持不变，因此九档阈值与 `certifyDaYunSPLUS`（L3181–L3267）不被结构性冲击。

### 3.4 土纳阴纳阳折算

土不整体归方，按原文「纳阴纳阳、随柱中寒热而折算」处理：

| 土 | 燥湿 | 纳方 | 建议系数 k |
|---|---|---|---|
| 戊、未、戌（燥土） | 燥 | 偏纳阳 | 0.35 |
| 己、丑、辰（湿土） | 湿 | 偏纳阴 | 0.35 |

**晦火存金特例**（夏月未戌）：对火作「晦」（削弱阳方 0.55）、对金作「存」（增强阴方 0.55）——沿用 `calculateColdHotBalance` L1862–L1864 已有的 `0.55` 量级，双面记账。

对外仍返回 `{ yang, yin }` 百分比结构不变（`calculateYinYangBalance` 签名 L1789 不动），仅替换内部折算方式。

### 3.5 权重标定（建议初值）

- `PILLAR_WEIGHTS` **保持不变**（月令最重、月支 2.5）。
- 二气判定阈值 `θ`：**0.06**（即 |阳−阴| 占比超过 6% 才判过、否则判均衡）——取初值偏保守，宁可判「均衡」也不误判「过」，避免 marks 大面积翻转。
- 长生归一化区间 `[−20,24]`、土折算 `0.35 / 0.55`、春秋硬条件——全部落为 CFG 字段。
- **回退开关**：新增 `YONG_JI_MODE = { version:'1.0.0', mode:'taiji' }`；`mode:'binary'` 时完全走旧 `usageDirection` 口径 → 一键回退，便于逐月灰度替换。
