## 三、大运 / 流年评分类意见

> 评分公式当前口径（2026-08-17 起生效）：  
>   `大运最终压缩分 = 大运本身压缩分(rawScoreDY/3.6) + 下辖十年流年平均压缩分`  
>   再 × 3.6 还原 rawScore → 映射五档：夯(>5) / 人上人(>2) / npc(≥-2) / 拉(≥-8) / 拉完了(<-8)

## 五、用神 / 忌神 / 命局模式类意见

<!-- 在此追加。建议附：月气阳气%/阴气%、原局偏枯弥合度明细 -->

### 【2026-08-17】土的喜用规则细化（judgeEarthXiJi）
- 位置：`src/utils/baziAnalyzer.ts` → `judgeEarthXiJi`
- 规则（月令季节 + 干支级 + 命局水气/阴阳）：
  - 冬月（亥子丑）：走土吉（四土皆可止寒制水；辰未首选、丑戌次之、戊己皆可用）
  - 夏月（巳午未）：丑戌吉；辰未「地支见水则凶、无水次选」（辰克水毁火、未燥晦火）
  - 秋月（申酉）：不宜土晦火 → 忌
  - 春月（寅卯）：土止寒固本；但「阴气不显」时也不要土克水 → 忌
- 判定依据（结合已加载模块）：
  - 「地支见水」＝命局四支中出现水支（亥／子），取自四柱排盘的地支。
  - 「阴气显不显」＝参照「寒热·阴阳占比」模块的阴气占比，< 30% 视为「不显」（阈值暂定，可调）。
- 待讨论：戊己（土之天干）在夏月「有吉有凶」，当前缺十神语境暂按「可用」处理，待十神信息接入后细化。

### 【2026-08-17】引入《太极阴阳法·年月分析核心基础》——底层断盘逻辑重构
- 位置：`src/data/bazidata.ts`（新书归纳数据）+ `src/utils/baziAnalyzer.ts`（`analyzeNianYueTaiJi` / `analyzeMingJuPattern` / `analyzeWealthNobility`）+ UI「命局模式分析」模块
- 新书核心：年为命局根本，年月组合构成命局核心太极，日时为动态应验环节；吉凶唯一依据为阴阳二气的存缺、损伤、平衡状态；十神不判富贵贫贱。
- 数据库新增：十二长生表（地支×十干）、五虎遁年上起月、月令太极两仪体系（春丙癸/秋丁壬/辰戌杂气通透/夏庚水救阴/冬丙甲暖阳）、年干先天定位与年支三类作用规则、甲X年·丙寅月六组典型格局。
- 引擎新增 `analyzeNianYueTaiJi`：五虎遁搭年月框架 → 年干定位（先天年吉/平/忌）→ 年支三类作用（落实兑现/阻碍否定/制衡借利）→ 两仪气机厚薄（十二长生量化+透干/藏干/无现+受克损伤）→ 年月太极三态（完整/受损/绝境）→ 日时动态应验（维护/破坏）→ 综合结论。
- 评价标准重写：
  - `analyzeMingJuPattern`：年月太极三态为首判（成局上等/受损中平/绝境偏枯），五行生克退为辅助。
  - `analyzeWealthNobility`：整体定调融入两仪修正（两仪完整升档、绝境降档），并附年月太极结论。
- 待验证：两仪气机的力量分阈值（完整≥50/40、受损≥20）、十二长生气机分档（±20 级）是否与老高手感一致，需多命例回归。
