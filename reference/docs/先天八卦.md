先天八卦（伏羲八卦）

导语
先天八卦，又称伏羲八卦、伏羲八卦方位，与后天八卦（文王八卦）相对，是易学象数体系中「体用」一对范畴里的「体」。其文字源头见于《周易·说卦传》「天地定位，山泽通气，雷风相薄，水火不相射，八卦相错」一节，其图式（先天图）依托宋儒邵雍（邵康节）的「先天之学」与「加一倍法」而传世，朱熹《周易本义》将其列为卷首九图之一。

本文件为资料沉淀，仅收集、校理先天八卦的文本与数理内容，供后续查阅与学习；当前不接入引擎计算、不参与用忌与评分，不作展示。

一、定义与别名

- 名称：先天八卦 / 伏羲八卦 / 伏羲八卦方位 / 先天图
- 相对者：后天八卦（文王八卦、文王八卦方位）
- 体用关系：先天为体，后天为用。先天主「对待」——阴阳相对而立，讲的是本然结构；后天主「流行」——五行相生、四时顺行，讲的是运转施用
- 传承脉络（传说性）：伏羲画卦 → 图自陈抟传出，经李之才授邵雍 → 邵雍《皇极经世》立「先天之学」→ 朱熹《周易本义》列入卷首诸图

二、典出原文（《周易·说卦传》）

天地定位，山泽通气，雷风相薄，水火不相射，八卦相错。数往者顺，知来者逆，是故易逆数也。

此节以「乾—坤」「艮—兑」「震—巽」「坎—离」四对相配，是先天八卦方位与「阴阳对待」的直接文字根据。

另，《说卦传》第十章以乾坤为父母、余六卦为六子，是先天八卦「父母六子」说的文本来源（见第七节）。

三、生成次序：加一倍法

「是故易有太极，是生两仪，两仪生四象，四象生八卦。」（《周易·系辞上》）

邵雍称此法为「加一倍法」：每级一分为二，自上而下逐级加倍而成卦，其卦序顺读即始《乾》而终《坤》。

| 层级 | 内容 |
|---|---|
| 太极 | 未分之初 |
| 两仪 | 阳（⚊）、阴（⚋） |
| 四象 | 太阳（⚊⚊）、少阴（⚊⚋）、少阳（⚋⚊）、太阴（⚋⚋） |
| 八卦 | 四象之上再各加一阳一阴，成八卦 |

四象生八卦的对应关系：

| 四象 | 加一阳（阳仪所生） | 加一阴（阴仪所生） |
|---|---|---|
| 太阳 | 乾 | 兑 |
| 少阴 | 离 | 震 |
| 少阳 | 巽 | 坎 |
| 太阴 | 艮 | 坤 |

四、先天八卦次序（横图）

伏羲八卦次序（自乾至坤）：

乾 一，兑 二，离 三，震 四，巽 五，坎 六，艮 七，坤 八。

即：乾 · 兑 · 离 · 震 · 巽 · 坎 · 艮 · 坤。

五、先天八卦方位（圆图）

邵子曰：「此伏羲八卦之位。《乾》南，《坤》北，《离》东，《坎》西，《兑》居东南，《震》居东北，《巽》居西南，《艮》居西北。于是八卦相交而成六十四卦，所谓先天之学也。」（朱熹《周易本义》引）

| 卦 | 方位 | 卦 | 方位 |
|---|---|---|---|
| 乾 | 南 | 坤 | 北 |
| 离 | 东 | 坎 | 西 |
| 兑 | 东南 | 震 | 东北 |
| 巽 | 西南 | 艮 | 西北 |

口诀示意（与《说卦传》相配）：

- 天地定位 —— 乾南（天，上）↔ 坤北（地，下）
- 山泽通气 —— 艮西北（山）↔ 兑东南（泽）
- 雷风相薄 —— 震东北（雷）↔ 巽西南（风）
- 水火不相射 —— 离东（火）↔ 坎西（水）

七、父母六子（《说卦传》）

乾，天也，故称乎父。坤，地也，故称乎母。震一索而得男，故谓之长男。巽一索而得女，故谓之长女。坎再索而得男，故谓之中男。离再索而得女，故谓之中女。艮三索而得男，故谓之少男。兑三索而得女，故谓之少女。

| 卦 | 亲属 | 说明 |
|---|---|---|
| 乾 | 父 | 三阳，纯阳之卦 |
| 坤 | 母 | 三阴，纯阴之卦 |
| 震 | 长男 | 一索得男（初爻得阳） |
| 巽 | 长女 | 一索得女（初爻得阴） |
| 坎 | 中男 | 再索得男（中爻得阳） |
| 离 | 中女 | 再索得女（中爻得阴） |
| 艮 | 少男 | 三索得男（上爻得阳） |
| 兑 | 少女 | 三索得女（上爻得阴） |

九、阴阳对待（相错）

先天八卦两两相对之位，卦爻阴阳恰好相反，是谓「八卦相错」：

| 对偶 | 方位 | 爻象关系 |
|---|---|---|
| 乾 ↔ 坤 | 南 ↔ 北 | 三阳 ↔ 三阴（全反） |
| 兑 ↔ 艮 | 东南 ↔ 西北 | 阳阳阴 ↔ 阴阴阳 |
| 离 ↔ 坎 | 东 ↔ 西 | 阳阴阳 ↔ 阴阳阴 |
| 震 ↔ 巽 | 东北 ↔ 西南 | 阳阴阴 ↔ 阴阳阳 |

此「对待」结构，即先天为「体」、主阴阳相对的实际含义。

十、先天八卦与后天八卦对比

| 比较项 | 先天八卦（伏羲） | 后天八卦（文王） |
|---|---|---|
| 别称 | 伏羲八卦方位 | 文王八卦方位 |
| 体用 | 为体 | 为用 |
| 主旨 | 对待（阴阳相对而立） | 流行（五行相生、四时顺行） |
| 文源 | 《说卦传》「天地定位…」节 | 《说卦传》「帝出乎震…」节 |
| 方位 | 乾南坤北，离东坎西；兑东南、震东北、巽西南、艮西北 | 离南坎北，震东兑西；巽东南、坤西南、乾西北、艮东北 |
| 卦序 | 乾一 兑二 离三 震四 巽五 坎六 艮七 坤八 | 帝出乎震 → 齐乎巽 → 相见乎离 → 致役乎坤 → 说言乎兑 → 战乎乾 → 劳乎坎 → 成言乎艮 |
| 数序 | 先天数（乾一…坤八） | 后天（洛书）数：坎一、坤二、震三、巽四、中五、乾六、兑七、艮八、离九 |

后天方位所依原文（《说卦传》）：帝出乎震，齐乎巽，相见乎离，致役乎坤，说言乎兑，战乎乾，劳乎坎，成言乎艮。

十一、数理旁证：加一倍法与二进制

- 邵雍《先天图》（八卦次序图、六十四卦次序图）卦序顺读始《乾》终《坤》，其「加一倍法」被论者认定即今天严格意义的二进制记数法。
- 以「阴＝0、阳＝1」计，伏羲六十四卦次序图恰对应二进制 0 至 63 的连续计数：坤（000000）＝0，乾（111111）＝63。
- 莱布尼茨见邵雍先天六十四卦次序图后，确认其与二进制计数一致；此为中国易学与西方二进制的一条著名对照材料。

十二、异说与辨析（存疑项）

- 「先天八卦于魏晋失传、至宋代再显」为一类流行说法，其确切程度取决于对「图」与「经」的界定，宜与「图式晚出」的考证观点并观，不宜径作定论。
- 学界对邵雍是否「真知」二进制存在争议：有论文指出先天卦图并非按二进制法则直接排序，而是依《周易》生成原理逐级递推而成（「递推算法」说），二进制的一致性是结果而非其构造动机。两说并存，列此备考。
