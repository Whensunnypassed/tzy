# 沛然堂 · 八字命理智能分析系统

> 以太极阴阳为体 · 以月气动应为用 · 以平衡为得失

**线上地址**：https://whensunnypassed.github.io/tzy/
**当前版本**：v2.4.3 · 正式版
**技术栈**：React 18 + Vite 5 + TypeScript + Tailwind CSS v4

---

## 项目简介

本工具基于天之易八字命理体系，输入出生信息后自动完成排盘与全维度命理分析，生成结构化、可视化的解读报告。所有计算均在用户本地浏览器完成，不上传任何个人数据。

### 核心功能

- 公历→农历→四柱自动排盘（含真太阳时校正、立春分界、五虎遁/五鼠遁）
- 十二月气分析与用神忌神判断
- 五行力量与阴阳平衡可视化
- 命局模式分析与富贵贫贱评定
- 八步大运与流年吉凶分析
- 象法分析（五行象意、财富应期）
- 手动四柱排盘模式
- 完整生辰一条栏快速输入
- 排盘历史记录（本地保存最近 10 次）
- 报告摘要复制与导出

## 开发说明

### 本地运行

```bash
npm install --legacy-peer-deps
npm run dev
```

### 构建

```bash
npm run build:pages
```

### 项目结构

```
src/
├── data/              # 静态数据（月气、十干喜忌、象法、节气主题）
├── utils/             # 核心引擎
│   ├── baziCalculator.ts   # 排盘计算
│   ├── baziAnalyzer.ts     # 分析引擎
│   └── xiangfaAnalyzer.ts  # 象法分析
└── pages/
    └── BaZiAnalyzerPage/   # 主页面
```

- `package.json` 版本号与页面 `APP_VERSION` 必须同步
