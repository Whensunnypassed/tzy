# 推步线 · 事层推导

> 状态：自建第一版。只用推步线自己的来源，不借子平、盲派、病药、十神。
> 目的：让推步线能独立回答“学业/事业/财/婚恋/健康”五类事，而不是拿别家的规则补洞。

## 〇 允许的素材（来源清单）

| 层 | 素材 | 出处 | 在本逻辑里的用途 |
|---|---|---|---|
| 时 | 月令地支、节气月 | 排盘层 | 定年周期相位 |
| 气 | 十二消息卦（复→坤） | 易·卦气说 | 给“常气”先验 P |
| 载 | 干禄、支命、身；胎月日时 10/10/8/10 | 李虚中《命书》卷中 | 定“域”的边界与权重 |
| 位 | 年/月/日/时 四宫 | 李虚中“胎月日时” | 定事落在人生哪一段、哪一类人 |
| 象 | 纳音五行、器识句 | 《命书》卷上 | 定“身/亲”的材质 |
| 类 | 五行类象、脏腑 | 《素问》五行大义 | 定“类”：学业/行业/身体 |
| 动 | 月将加时 k | 大六壬 | 只定结构关系，不定吉凶 |
| 应 | 冲合刑害 | 干支公共语法 | 只标“何时动”，不标“动成什么” |

**不用**：十神、财官印比、身强身弱、病药、神煞、纳音生克吉凶、任何“某星主某事”的对应。
**理由**：那些是别家的语义层；本线只承认上表七样，其余一律标“本线判不了”。

## 一 本体：气位

每一个干支是一个**气位**，记 `p = {stem, branch, q, palace, weight}`。

- `q`：该气位的气量。干按“旺相休囚死”定（当令 1.0，次旺 0.6，泄 0，克我 −0.5，我克 −0.9）；支按藏干份额折算，再乘 0.75。
- `palace`：年=祖上/外部，月=父母门户，日=自身配偶，时=子女晚境。
- `weight`：胎月日时 = 10/10/8/10，归一为 1.0/1.6/1.2/0.8。

这是李虚中“三元”的下沉：干禄看名，支命看财，纳音身看器识。本线不搬纳音生克，身只取“器识句 + 日支宫位”。

## 二 域：事的载体

事不在“星”上，在**域**上。四域 = 禄、财、身、亲。

| 域 | 成员 | 读什么 | 宫位对应 |
|---|---|---|---|
| 禄 | 四柱天干（+运年干） | 名禄、贵权、考试之名 | 年=外部名分，月=门户名分 |
| 财 | 四柱地支（+运年支） | 金珠积富、资源 | 年=祖业，月=家计 |
| 身 | 日柱（干+支） | 材能器识、学业、身体 | 日=自身 |
| 亲 | 日支 + 时柱 | 配偶、子女、人伦 | 日支=配偶，时=子女 |

域的**体**：`bod_d = {q_d, fit_d}`，其中 `fit_d = 1 − |q_d − q_身| / 2`。
合身度不是好坏，是“这个域和本人的气质合不合”。

## 三 时：运与年

运、年是**追加气位**，不是另一套算法：

- 大运干支：权重 1.4；
- 流年干支：权重 1.0；
- 加入后重算各域 `q_d(t)`，`Δq_d(t) = q_d(t) − q_d(0)`。

`Δq_d > 0` 读“该域得气”（扩张、被看见、成事的机会增）；`< 0` 读“失气”（收缩、被压、断）。**这是本线的假设，不是古籍原文，必须被盘验。**

## 四 五条规则（每条都标“假设/公理”）

- **R1 显隐（公理）**：域中任一地支与运/年地支成 合、冲、害、刑 → 该域当年“显”（事情浮出水面）；否则“隐”（潜在，不显事）。
- **R2 顺逆（假设）**：`Δq ≥ +0.05 且 fit ≥ 0.5` → 顺；`Δq ≤ −0.05 且 fit < 0.5` → 逆；其余平。阈值 0.05 是初值，可用盘校。
- **R3 强弱（假设）**：`|Δq| × fit` 分四档：微/小/中/大。
- **R4 事类（公理+类象表）**：域定“哪一块”，五行定“哪一类”。禄域取干之五行，财域取支藏干主气，身域取纳音五行，亲域取日支五行。
- **R5 时窗（公理）**：显的年份为窗口；窗口前后各一年给“边界年”（气已动、事未显）。

## 五 五类事的完整判法

1. **学业**：身域体（器识）+ 少年运（11–21）Δq 的均值 + 禄域名位。身强名弱 → 能力先于文凭；名强身弱 → 文凭先于能力；双弱 → 早入实务。
2. **事业**：禄域体 + 当前运/年 Δq + 财域 fit。禄得气且财合 → 名实俱进；禄得气财背 → 有职无权；禄失气 → 退名守实。
3. **财**：财域体 + Δq + 触发。财显且得气 → 进项窗口；财显且失气 → 支出/纠纷窗口；财隐 → 不显财事。
4. **婚恋**：亲域体 + 日支/时支触发 + 纳音象（身之材质：藏/露、静/动）。
5. **健康**：五行占比最低者 → 对应脏腑（内经），只作倾向提示，不判病、不判寿。

## 六 与子平的分界（写死）

- 不出现“十神/财星/官杀/印/食伤/比劫”等词做判据。
- 不判“身强身弱”，只判“域与身合不合”。
- 不判寿夭、不判具体事件背书。
- 任何一条规则若借了别家语义，必须删除或改写成“可验假设”。

## 七 验证计划

- 内部：8 盘 × 5 类，检查五类是否都有输出、是否出现“全顺/全逆”的荒谬分布、阈值是否让 80% 年份落在“平”。
- 外部：老高 50 例，逐例记“体/用/时/类/顺逆”，算命中率与 Wilson 区间。
- 验收：五类都能给出判断且自检通过，才向主人汇报“能判断”。
