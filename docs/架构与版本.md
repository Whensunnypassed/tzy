# 架构与版本（天枢）

> 本文件记录系统分层、数据流、重构路线与版本命名规则。代码改动以本文件为准。

## 一、版本命名

2026-11-03 起启用「代号 + 版本号」制，不再沿用 `2.x`：

| 项 | 当前值 |
| --- | --- |
| 代号 | **天枢（北斗第一星）** |
| 版本 | **天枢 1.1.0**（推送前冻结，不随开发改动递增） |
| 规则 | 代号随大代际更换；同一代号内用 `主.次.修订`（如 天枢 1.1.0） |
| 同步位置 | `package.json`（version + codename）、页脚 `APP_VERSION`、`CHANGELOG.md` |

## 二、分层

```
src/analysis/
├─ common/                 公共层（两条线共用）
│   ├─ baziCalculator.ts   排盘：真太阳时 / 节气 / 四柱 / 大运 / 起运
│   ├─ solarTermsCalc.ts   节气儒略日与时刻计算
│   └─ context.ts          buildYinyangContext：阴阳线上下文装配
├─ yinyang/                阴阳线工作区（原有全部逻辑）
│   ├─ engine.ts           月气、用忌、五行力量、格局、富贵、综合分、大运流年、六亲健康
│   ├─ xiangfa.ts          象意：财富/地位/学历/婚姻/健康 + 流年财富贵气评分
│   └─ index.ts            buildYinyangAnalysis：原月气口径完整报告
└─ peiran/                 沛然堂线工作区（独立纳音体系）
    ├─ nayinData.ts        六十纳音取象、喜忌、性情、盲派纳音长生、兰台妙选象格
    ├─ nayinAnalyzer.ts    年命为身、四柱纳音生克链、刑冲三合纯旺、大运流年
    └─ index.ts            buildPeiranAnalysis：纳音完整报告

BaZiAnalyzerPage         展示层：01 共用；02–06 按选中线分别渲染
PeiranLine/PeiranReport  沛然堂线 02–05 纳音报告
```

- 两条线互不依赖：阴阳线走月气/用忌/正五行；沛然堂线走纳音年命/四柱纳音生克。
- 公共层只保留排盘、节气与通用类型；沛然堂线不读取 `yinyang/engine.ts`。
- 展示层不再 import `utils/*` 旧路径，统一从 `@/analysis` 取用。

## 三、数据流（单一真相源）

```
出生信息
  → calculateBaZi()
  ├─ 阴阳线：buildYinyangContext(chart, currentYear)
  │    ├─ monthQi / yongJi / elementPower
  │    ├─ pattern / wealthNobility / mingPanScore
  │    └─ daYunAnalysis
  └─ 沛然堂线：buildPeiranAnalysis(chart, currentYear)
       ├─ 年命纳音（身）/ 日柱纳音 / 胎元纳音
       ├─ 四柱纳音生克链 / 身强弱 / 刑冲 / 三合 / 纯旺
       ├─ 日柱纳音性情 / 盲派纳音长生
       └─ 大运纳音 / 流年纳音 / 兰台妙选象格
```

**不变量**：
1. 排盘层（baziCalculator）不做展示、不依赖上层。
2. 阴阳线的用神/忌神只有一处真相源：`analyzeYongJi`。
3. 沛然堂线不读取阴阳线的月气、用忌、五行力量与评分，只共用排盘与节气。
4. 五行力量只有一处真相源：`calculateElementPower`（仅阴阳线使用）。
5. 01 排盘始终可见；阴阳线展开 02–06，沛然堂线展开 02–05，版块编号与内容各自独立。

| 1 | 同一概念多出口：财富有 `analyzeWealthNobility`（分数）/ `analyzeWealthVerdict`（文案）/ `scoreWealthForYear`（流年） | baziAnalyzer / xiangfaAnalyzer |

## 五、双线体系：阴阳线 / 沛然堂线

从「用神忌神」判断开始，系统并行维护两条互不依赖的线；UI 在 01 排盘后提供两个大按钮切换：

| 线 | 规则 | 用途 |
| --- | --- | --- |
| **阴阳线** | 现行整套逻辑：月气、用忌、五行力量、格局、富贵、综合分、大运流年、象意 | 原功能全部保留，一字不改 |
| **沛然堂线** | 独立纳音体系：年柱纳音为身，四柱纳音生克链、刑冲、三合、纯旺、日柱纳音性情、盲派纳音长生、大运流年纳音、兰台妙选象格 | 纳音断命完整报告，不读取阴阳线引擎 |

- 阴阳线入口：[`src/analysis/yinyang/index.ts`](../src/analysis/yinyang/index.ts)
- 沛然堂线入口：[`src/analysis/peiran/index.ts`](../src/analysis/peiran/index.ts)
- 纳音数据书：[`src/analysis/peiran/nayinData.ts`](../src/analysis/peiran/nayinData.ts)
- 纳音引擎：[`src/analysis/peiran/nayinAnalyzer.ts`](../src/analysis/peiran/nayinAnalyzer.ts)
- 线规则总表：[`src/analysis/peiran/README.md`](../src/analysis/peiran/README.md)
- 纳音报告：[`src/pages/PeiranLine/PeiranReport.tsx`](../src/pages/PeiranLine/PeiranReport.tsx)
- UI 行为：01 四柱排盘后默认隐藏后续版块；点击「阴阳线」展开原 02–06，点击「沛然堂线」展开纳音 02–05，可随时收起或切换
- 大运/流年吉凶：v1.1 评分制，年命纳音关系 + 日柱纳音十二运分别计分，总分 ≥ +1.5 吉、≤ −1.5 凶，其余为平
- 口径提醒：沛然堂线的纳音长生采用盲派「水申木亥金辰火卯土午」口径，与正五行长生不同

## 六、重构路线

> 版本号冻结在 **天枢 1.1.0**，推送前不随开发改动递增；以下完成项均记入「未发布」。

   - `buildAnalysisContext(chart, currentYear)` 一次计算，UI 只读
2. **双线工作区拆分**（已完成，未发布）

   - 01 后默认隐藏 02–06，两个大按钮切换完整报告
3. **沛然堂线改为独立纳音体系**（已完成，未发布）

   - 沛然堂线不读取阴阳线引擎，02–05 使用纳音版块
4. **学历合并为单一 evaluator**（待做）
   - 取消 `scoreEducationLevel` 与 `analyzeEducationVerdict` 的双出口，只保留一个返回 `{ score, level, factors[], evidence[] }`
