> 本文件记录系统分层、数据流、重构路线与版本命名规则。代码改动以本文件为准。

| --- | --- |

## 二、分层

```

│   ├─ baziCalculator.ts   排盘：真太阳时 / 节气 / 四柱 / 大运 / 起运
│   ├─ solarTermsCalc.ts   节气儒略日与时刻计算
│   └─ context.ts          buildYinyangContext：阴阳线上下文装配
├─ yinyang/                阴阳线工作区（原有全部逻辑）
│   ├─ engine.ts           月气、用忌、五行力量、格局、富贵、综合分、大运流年、六亲健康
│   ├─ xiangfa.ts          象意：财富/地位/学历/婚姻/健康 + 流年财富贵气评分
│   └─ index.ts            buildYinyangAnalysis：原月气口径完整报告
└─ greek/                  希腊线（希腊占星）
    ├─ ephemeris.ts        七政黄历（VSOP87 / Meeus，对 JPL DE441 ≤3 角分）
    ├─ astroChart.ts       恒星时 / 轴点 / 整宫制 / 宗派 / 整宫相位
    ├─ tables.ts           静态规则表（庙旺陷落 / 三分 / 埃及界 / 面 / 喜乐宫 /
    │                       黄道释放年数 / 法尔达利亚 / 七虚点定义）
    ├─ dignity.ts          尊贵判定 + 点位 almuten 计分
    ├─ lots.ts             七虚点（Paulus 定义，昼夜互换）
    ├─ planetaryState.ts   行星状态（东出西入 / 燃烧 / 疾迟 / 喜乐宫 / 宗派半球）
    ├─ aspects.ts          度相位 / 应用分离 / 空亡 / 映照 / 光线收集
    ├─ timeLords.ts        周年推运 / 黄道释放 L1–L2 / 法尔达利亚 / 太阳返照
    ├─ selfCheck.ts        自检：规则表全称性 / 星盘不变量 / 跨模块一致性
    ├─ analysis.ts         汇总装配 buildGreekModel（展示层只读）
    └─ index.ts            GREEK_LINE + 全部 API 出口
├─ index.ts                统一出口（yinyang / greek / zalu / common）

src/data/cityData.ts      城市库：187 城经纬度 + 历史时区规则（唯一真源）

GreekLine/GreekReport    希腊线事实面板（7 版块，不写断论）

```

- 三线并列：阴阳线（元素级）/ 希腊线（希腊占星事实层）/ 大杂烩线（门派登记簿，只登记不判命）。推步线已于 2026-11-05 整体删除。

- 阴阳线走月气/用忌/正五行；希腊线走希腊占星事实层（引擎已完整，判读层未启用）。
- 公共层只保留排盘、节气与通用类型。
- 展示层不再 import `utils/*` 旧路径，统一从 `@/analysis` 取用。

## 三、数据流（单一真相源）

```
出生信息（日期 / 时刻 / 城市）
  → calculateBaZi()                     中国口径：真太阳时 + 节气
  ├─ 阴阳线：buildYinyangContext(chart, currentYear)
  │    ├─ monthQi / yongJi / elementPower
  │    ├─ pattern / wealthNobility / mingPanScore
  │    └─ daYunAnalysis
  └─ 希腊线：buildAstroChart(输入 + 城市) → buildGreekModelFromChart
       ├─ 星盘事实：七政黄经 / ASC / MC / 整宫制 / 宗派 / 整宫相位
       ├─ 尊贵：庙旺陷落 + 三分 + 埃及界 + 面 + 点位 almuten
       ├─ 虚点：七虚点（Paulus，昼夜互换）
       ├─ 状态：东出西入 / 燃烧 / 疾迟 / 喜乐宫 / 宗派半球
       ├─ 相位：度相位（orb + 应用分离）/ 空亡 / 映照 / 光线收集
       ├─ 时间主星：周年推运 / 黄道释放 L1–L2 / 法尔达利亚 / 太阳返照
       └─ 自检：规则表 + 星盘不变量 + 跨模块一致性
```

**不变量**：
1. 排盘层（baziCalculator）不做展示、不依赖上层。
2. 阴阳线的用神/忌神只有一处真相源：`analyzeYongJi`。
3. 城市经纬度与时区只有一处真相源：`src/data/cityData.ts`（`CITY_DB` + `resolveUtcOffsetMinutes`）；未收录城市一律按北京经纬度计算，UI 必须提示。
4. 五行力量只有一处真相源：`calculateElementPower`（仅阴阳线使用）。
5. 希腊占星的全部规则只有一处真相源：`tables.ts`；引擎不得在函数体内硬编码规则表。
6. 展示层只读 `GreekModel`，不自行重算尊贵/虚点/时间主星（避免口径分叉）。
7. 01 排盘始终可见；阴阳线展开 02–06，希腊线展开事实面板（默认 01–07）。
8. 两套日数历元不可混用：行星算法用 `daysSinceJ2000`（Schlyter 历元 1999-12-31 00:00），恒星时用 `daysSinceJ2000UT`（真 J2000）。
9. 希腊占星线当前**只输出事实，不输出断论**；判读层启用前不得在页面写入人事结论。

## 五、三线体系：阴阳线 / 希腊线 / 大杂烩线

系统并行维护三条线；UI 在 01 排盘后提供三个大按钮切换：

| 线 | 状态 | 用途 |
| --- | --- | --- |
| **阴阳线** | 现行整套逻辑：月气、用忌、五行力量、格局、富贵、综合分、大运流年、象意 | 原功能全部保留，一字不改 |
| **希腊线** | 希腊占星：城市经纬度 + 自研星历 → 宗派 / 轴点 / 七政落座 / 整宫制 / 相位 → 尊贵 / 虚点 / 阿拉伯点 / 时间主星 → 六主题区间判读（判读层已启用） | 主干希腊占星，阿拉伯中世纪技法作扩展层 |
| **大杂烩线** | 各派取一条可落成规则的判据（印星 / 月令 / 宫位 / 财官 / 冲合），断学业、爱情、财富 | 登记 20 门、21 本书目；回测见 `scripts/zalu-backtest.mjs` |

- 方向决策依据与资料台账：[`docs/astrology/resources.md`](astrology/resources.md)
- 选型理由：阿拉伯体系是希腊体系的翻译与注释分支，Dorotheus 原典即靠 9 世纪阿拉伯译本存世；
  希腊做主干可吸收阿拉伯技法（虚点扩充、法尔达利亚、太阳返照、almuten、大合相）为扩展层，
  反向则须先重建整个希腊底层。工程侧原计划采用 MIT 纯 TypeScript 引擎 caelus，
  但本机 npm 安装被系统权限拦截（EPERM），改为同算法的自研实现，仍满足"本地纯前端计算"承诺。

- 阴阳线入口：[`src/analysis/yinyang/index.ts`](../src/analysis/yinyang/index.ts)
- 希腊线（希腊占星）：[`src/analysis/greek/index.ts`](../src/analysis/greek/index.ts)
- 星盘页：[`src/pages/GreekLine/GreekReport.tsx`](../src/pages/GreekLine/GreekReport.tsx)
- 大杂烩线：登记 [`src/analysis/zalu/index.ts`](../src/analysis/zalu/index.ts)、书目 [`books.ts`](../src/analysis/zalu/books.ts)、断法 [`judge.ts`](../src/analysis/zalu/judge.ts)、页面 [`src/pages/ZaluLine/ZaluReport.tsx`](../src/pages/ZaluLine/ZaluReport.tsx)
- 城市与时区：[`src/data/cityData.ts`](../src/data/cityData.ts)
- UI 行为：01 四柱排盘后默认隐藏后续版块；点击「阴阳线」展开原 02–06，点击「希腊线」展开星盘页，点击「大杂烩线」展开三判，可随时收起或切换
