# 架构与版本（天枢）

> 本文件记录系统分层、数据流、重构路线与版本命名规则。代码改动以本文件为准。

## 一、版本命名

2026-11-03 起启用「代号 + 版本号」制，不再沿用 `2.x`：

| 项 | 当前值 |
| --- | --- |
| 代号 | **天枢（北斗第一星）** |
| 版本 | **天枢 1.1.0**（推送前冻结，不随开发改动递增） |
| 规则 | 代号随大代际更换；同一代号内用 `主.次.修订`（如 天枢 1.1.0） |
| 同步位置 | `package.json`（version + codename）、页脚 `APP_VERSION`、`CHANGELOG.md` |

## 二、分层

```
src/analysis/
├─ common/                 公共层（两条线共用）
│   ├─ baziCalculator.ts   排盘：真太阳时 / 节气 / 四柱 / 大运 / 起运
│   ├─ solarTermsCalc.ts   节气儒略日与时刻计算
│   └─ context.ts          buildYinyangContext：阴阳线上下文装配
├─ yinyang/                阴阳线工作区（原有全部逻辑）
│   ├─ engine.ts           月气、用忌、五行力量、格局、富贵、综合分、大运流年、六亲健康
│   ├─ xiangfa.ts          象意：财富/地位/学历/婚姻/健康 + 流年财富贵气评分
│   └─ index.ts            buildYinyangAnalysis：原月气口径完整报告
└─ peiran/                 沛然堂线占位（空壳，待重建）
    └─ index.ts            仅保留 PEIRAN_LINE 占位常量，无引擎、无数据书

BaZiAnalyzerPage         展示层：01 共用；02–06 按选中线分别渲染
PeiranLine/PeiranReport  沛然堂线占位页（空状态）
```

- 阴阳线走月气/用忌/正五行；沛然堂线已清空，当前只有入口与空状态。
- 公共层只保留排盘、节气与通用类型。
- 展示层不再 import `utils/*` 旧路径，统一从 `@/analysis` 取用。

## 三、数据流（单一真相源）

```
出生信息
  → calculateBaZi()
  ├─ 阴阳线：buildYinyangContext(chart, currentYear)
  │    ├─ monthQi / yongJi / elementPower
  │    ├─ pattern / wealthNobility / mingPanScore
  │    └─ daYunAnalysis
  └─ 沛然堂线：空壳占位（无分析数据流）
```

**不变量**：
1. 排盘层（baziCalculator）不做展示、不依赖上层。
2. 阴阳线的用神/忌神只有一处真相源：`analyzeYongJi`。
3. 沛然堂线当前不产生任何分析数据，只保留入口与空状态。
4. 五行力量只有一处真相源：`calculateElementPower`（仅阴阳线使用）。
5. 01 排盘始终可见；阴阳线展开 02–06，沛然堂线显示空壳提示。

| 1 | 同一概念多出口：财富有 `analyzeWealthNobility`（分数）/ `analyzeWealthVerdict`（文案）/ `scoreWealthForYear`（流年） | baziAnalyzer / xiangfaAnalyzer |

## 五、双线体系：阴阳线 / 沛然堂线（空壳）

从「用神忌神」判断开始，系统并行维护两条线；UI 在 01 排盘后提供两个大按钮切换：

| 线 | 状态 | 用途 |
| --- | --- | --- |
| **阴阳线** | 现行整套逻辑：月气、用忌、五行力量、格局、富贵、综合分、大运流年、象意 | 原功能全部保留，一字不改 |
| **沛然堂线** | 空壳：入口与占位页保留，原纳音引擎、数据书、五维、回测与研究文档已清空 | 等待重建 |

- 阴阳线入口：[`src/analysis/yinyang/index.ts`](../src/analysis/yinyang/index.ts)
- 沛然堂线占位：[`src/analysis/peiran/index.ts`](../src/analysis/peiran/index.ts)
- 占位页：[`src/pages/PeiranLine/PeiranReport.tsx`](../src/pages/PeiranLine/PeiranReport.tsx)
- UI 行为：01 四柱排盘后默认隐藏后续版块；点击「阴阳线」展开原 02–06，点击「沛然堂线」显示空状态，可随时收起或切换
