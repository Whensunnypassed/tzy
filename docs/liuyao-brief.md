# 六爻简报

> 性质：研究资料（不入库）。用途：为推步线的「触发层」与表达层的「状态标记」提供参照。
> 说明：本文由 2026-11-04 会话中的六爻专题研究整理成文，属**整理稿**，不是古籍原文全集。

## 一 是什么

六爻，又称纳甲筮法、火珠林法，是《周易》象数体系里唯一「以钱代蓍、装卦断事」的民间主流占法。与八字同属「干支 + 五行 + 六亲」语法，但**输入是随机起卦，不是出生时间**。

## 二 源流

- 西汉京房创纳甲、八宫、世应、六亲，是六爻的直接源头。
- 唐末五代《火珠林》以钱代蓍，六爻定型。
- 明清《增删卜易》《卜筮正宗》《易隐》集大成，断法趋于口诀化。

## 三 起卦与装卦

### 3.1 起卦

三枚铜钱掷六次，自下而上成六爻：一背为单（阳）、二背为拆（阴）、三背为重（老阳，动）、无背为交（老阴，动）。动爻变出之卦为变卦。

### 3.2 八宫与世应

六十四卦分八宫（乾、兑、离、震、巽、坎、艮、坤），每宫八卦，按「变初、变二、变三、变四、变五、游魂（变四）、归魂（三爻全变）」生成；世爻位置：八纯世六、一世初、二世二……游魂世四、归魂世三；应爻与世爻隔两位。

### 3.3 纳甲

|---|---|---|---|
| 乾 | 甲壬 | 子寅辰 | 午申戌 |
| 坤 | 乙癸 | 未巳卯 | 丑亥酉 |

| 巽 | 辛 | 丑亥酉 | 未巳卯 |
| 坎 | 戊 | 寅辰午 | 申戌子 |
| 离 | 己 | 卯丑亥 | 酉未巳 |

阳卦顺行、阴卦逆行。每爻得到一个地支，再按五行配六亲。

### 3.4 六亲与六神

- 六亲以卦宫五行为「我」：生我者父母、我生者子孙、克我者官鬼、我克者妻财、比和者兄弟。
- 六神以日干起：甲乙青龙、丙丁朱雀、戊勾陈、己螣蛇、庚辛白虎、壬癸玄武，自初爻顺布。

## 四 判据

### 4.1 用神

占何事取何六亲为用神；用神不上卦则取伏神，或取世应。**用神是断事的焦点**。

### 4.2 月建与日辰（双时间尺度）

- **月建**（占时月支）：定旺相休囚死与月破——「月建为提纲」。
- **日辰**（占时日支）：主生克冲合、旬空、暗动——「日辰为主宰」。
- 关键判据：月破（月建冲爻）、旬空（日柱空亡）、暗动（静爻被日辰冲而旺）、日辰生克。

### 4.3 动变

动爻为事之机：动而化回头生/克、化进神/退神、化空/化破、化墓绝。变爻只对动爻起作用，不能生克他爻。

### 4.4 合冲刑害

三合局（申子辰等）、六合、三刑、六冲；合处逢冲、冲中逢合。

### 4.5 应期

合待冲、冲待合、空待填实、动待合、静待冲；以用神与动爻的地支定月份/日辰。

## 五 关键结论

1. **六爻没有「气」的配比概念**。它的旺衰是「旺相休囚死」五档定性，不是连续量；把六爻的旺衰折算成阴阳二气配比，是范畴错误。
2. **六爻的随机性不可消除**。起卦本身是随机变量，同一人反复占同一事，卦不同、结论不同。推步线若借用，只能借结构，不能借输入。
3. **月建（慢）—日辰（快）双尺度**是六爻最可迁移的洞见：慢变量定格局、快变量定触发。
4. **六亲与十神同构**：都是以「我」为中心的五种关系算子，可互相校验。

## 六 与推步线的接口

| 六爻 | 推步线 | 迁移方式 |
|---|---|---|
| 世应 | 本 / 用（体用二元） | 结构参照，不搬六亲取用 |
| 月建 / 日辰 | 慢钟（节气月）/ 快钟（流月流日） | 双时间尺度直接采用 |
| 用神 | 判据焦点 | 只借「焦点思维」，不借用神取法 |
| 旬空 / 月破 / 暗动 / 回头克 | 状态标记 | 挂状态、不并入总分 |
| 六神 | 无 | 不吸收 |
| 卦爻辞、变卦 | 无 | 不吸收 |

**结论**：六爻对推步线的价值在「触发层」：用神＝哪一维读数在动；动爻＝哪根柱/哪步运在动；应期＝什么时候可能应。全部只作**窗口与标记**，不进二气配比。

## 七 待考

- 《火珠林》作者与成书年代（托名麻衣道者，实出唐末五代）。
- 纳甲表各本小异（尤其坎离震兑的内外卦地支），以京房本为准还是以《增删卜易》为准，需逐本核对。
- 六神吉凶断语在明清以后大量增补，属「可无限增补、不可证伪」的层，本文不采。
