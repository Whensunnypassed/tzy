# 沛然堂线 · 希腊占星资料与资源汇编

> 立项结论（2026-11-03）：沛然堂线重建方向定为**希腊占星（Hellenistic Astrology）为主干**，
> 阿拉伯中世纪技法（虚点扩充、法尔达利亚、太阳返照、almuten 计分、大合相）作为**扩展层**叠加。
> 理由：阿拉伯体系是希腊体系的翻译与注释分支，Dorotheus 希腊原典即靠 9 世纪阿拉伯译本存世；
> 选希腊做主干可直接吸收阿拉伯精华，反之则须先重建整个希腊底层。
>
> 本文件为资料台账，只记录可核验来源，不做理论改写。

## 一、体系边界（先厘清三个"希腊"）

| 名称 | 时间 | 内容 | 本项目取用 |
| --- | --- | --- | --- |
| 希腊化占星 Hellenistic | 前 1 世纪 – 7 世纪 | 宗派、整宫制、七行星、虚点、时间主星 | **主干** |
| 阿拉伯/中世纪 Arabic-Medieval | 8 – 13 世纪 | 虚点扩充、almuten、法尔达利亚、返照、卜卦法典化、大合相 | 扩展层 |
| 拜占庭汇编 Byzantine | 4 – 7 世纪 | Paulus、Hephaistion、Rhetorius 的教科书式汇编 | 主干教材来源 |

关键事实：所谓"阿拉伯虚点"（Arabic Parts）实为希腊 klēroi；Paulus Alexandrinus 定型 7 个，
阿拉伯学者扩至约 97 个（Abu Ma'shar）乃至后世数百个。名称是传播路径的产物，不是起源。

## 三、现代教材与学习路径（P1）

### 3.1 体系化教科书（按推荐顺序）

1. **Chris Brennan, *Hellenistic Astrology: The Study of Fate and Fortune***（Amor Fati, 2017）
   现代希腊占星的标准教科书，含历史、技法与判读；配套 *The Astrology Podcast*（已逾 500 期）。
   **中文版**：《希臘占星學：命定與吉凶的研究》，商周出版，2023-06-10，瑪碁斯審定。
2. **Demetra George, *Ancient Astrology in Theory and Practice***
   Vol I《Assessing Planetary Condition》（Rubedo Press, 2019，622 页）、Vol II《Delineating Planetary Meaning》。
   训练手册体例：每技法配图、实例盘与练习。**这是最适合转写成规则表的一本。**
3. **Benjamin Dykes, *Traditional Astrologer* 系列**（本命、卜卦、择时、波斯/阿拉伯分区）
   含《當代古典占星研究》中译（希斯莉译，商周 2013）——入门第一本。
4. **《薩爾占星全集》**（繁中，三冊）：汇集 Dorotheus、Ptolemy、Valens、Rhetorius、Theophilus、Masha'allah 等，卜卦取向。

## 四、技法 → 可编码性 → 本项目映射

| 希腊/阿拉伯技法 | 输入 | 判定性质 | 本项目现有对应 | caelus 模块 |
| --- | --- | --- | --- | --- |
| 宗派 sect（昼/夜盘） | 太阳相对地平线 | 确定性布尔 | 无 | `chart` |
| 整宫制 whole-sign houses | ASC 所在星座 | 确定性 | 无（八字用宫位另有体系） | `houses` |
| 三分主星 triplicity lords | 星座 + 宗派 | 查表 | 无 | `dignity-score` |
| 界 bounds / 面 decans | 黄经度数 | 查表（埃及界/托勒密界两版） | 无 | `dignity-score` |
| 虚点 Lots（ASC + A − B） | ASC、两行星黄经 | 确定性公式 | 无 | `lots` |
| 行星喜乐 planetary joys | 宫位 | 静态表 | 无 | `patterns` |
| 映照/ aversion | 星座间距 | 规则 | 无 | `chart` |
| 周年推运 profections | ASC + 年龄 | 确定性 | ≈ 流年（但不是同一物） | `profections` |
| 黄道释放 ZR | 虚点所在星座 | 确定性时间轴（含 loosing of the bond） | ≈ 大运分期 | `releasing` |
| 主方向 primary directions | 赤经赤纬 + 时间 | 天文计算 | 无 | `directions` |
| 法尔达利亚（阿拉伯） | 宗派 + 年龄 | 查表（昼 75 年 9 期） | ≈ 大运 | `firdaria` |
| 太阳返照（阿拉伯） | 返照时刻盘 | 天文 + 判读 | ≈ 流年 | `derived` |
| 大合相（阿拉伯） | 木土会合周期 | 天文 + 历史 | 无 | `events` / `query` |

结论：**本命层（sect/宫/尊贵/虚点）+ 时间层（profections/释放/方向/firdaria/返照）几乎全部可确定性编码**；
真正难编码的是判读话术（"金星受克主婚姻不利"这类），与本项目八字线的处理方式相同——规则表 + 评分器 + 文本模板。

### 9.4 阿拉伯点（Arabic Parts）落地清单
