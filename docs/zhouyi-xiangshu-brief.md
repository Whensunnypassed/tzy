# 周易象数体系：面向「二气判据」引擎的结构化简报

## 一、符号系统的最小完备集

### 1.1 实体

- **爻 Yao**：`{位: 1..6, 性: 阴|阳}`。属性只有两样：阴阳与位序。**无五行、无干支、无十神、无六亲。**
- **卦 Gua**：6 爻有序元组；**八卦 JingGua**：3 爻元组，兼作「经卦」用于重叠取象。
- **位 Wei**：1–6，兼含奇偶（位之阴阳）、上下卦归属、内外、贵贱（五为君位）。
- **时 Shi**：卦/爻所主之月、候、日 —— 是**外挂索引**，不是卦内属性。

### 1.2 关系

```
卦 —has— 爻[6]            // 有序，位固定，位不可交换
卦 —has— 卦[2]            // 上卦/下卦（经卦）
爻 —relation— 爻
   ├ 应   : (1,4)(2,5)(3,6)；阴阳相异为「有应」，同为「无应/敌应」
   ├ 比   : 相邻 (i, i+1)
   ├ 承/乘: 相邻；下对上为承，上压下为乘（阴乘阳为逆）
   ├ 中   : 二、五爻
   ├ 当位 : 阳爻居奇位 / 阴爻居偶位；反之为不当位
   └ 中正 : 中 ∧ 当位
卦 —relation— 卦
   ├ 错(旁通): 六爻全变
   ├ 综(反卦): 上下颠倒
   ├ 互      : 2-3-4 为下互，3-4-5 为上互
   ├ 之/变   : 某爻动而之彼卦
   └ 序      : 今本序卦 / 八宫世应 / 帛书次序（三套互不兼容）
```

### 1.3 关键判定：爻本身没有五行

**没有。** 五行是在三个不同层级被「外挂」上去的，且挂法互不相同：

| 挂载层 | 挂在哪 | 传导链 | 出处层级 |
|---|---|---|---|
| 卦层方位五行 | 经卦（3 爻整体） | 后天方位 → 五行 | 《说卦》方位系统 |
| 纳甲（京房） | 爻 → 经卦 → 天干 → 地支 | 干支配五行，**五行是干支带来的** | 京房 |
| 爻辰（郑玄） | 爻 → 十二辰 | 辰配五行，机械对应 | 郑玄 |

建模结论：

```
爻 { 位, 阴阳 }              // 纯符号本体，永不写五行
Annotation { yaoRef, ganZhi?, element?, layer: 'najia'|'yaochen'|'guaqi' }
```

即五行必须是**可插拔的标注层**，与爻本体解耦；三套挂法可并存但不得混算。六爻占里「父克子」的生克，本质是纳甲干支五行的生克，不是爻与爻的生克——这一点若不拆开，后面一定会双重计数。

## 二、象数三支

### 2.1 卦气说（孟喜—京房）

**规则**：四正卦（坎震离兑）主二至二分，二十四爻主二十四气；其余六十卦配 365¼ 日，**每卦六日七分**（1 日 = 80 分，故 6.0875 日）；十二辟卦为月主，各统公、辟、侯、大夫、卿五卦；七十二候由十二辟卦 × 6 爻 = 72，一爻主一候（5 日）。

**边界**：依附四分历，岁差与置闰使「日—卦」对应长期漂移；且它是**公共年历**，不是个人命局。

**评价**：三支中唯一把「时间轴 → 爻位阴阳 → 气之消长」写成连续函数的体系。**最接近「用时间推气」的模型。**

### 2.2 纳甲（京房）

**规则**：八卦纳天干（乾甲壬、坤乙癸、震庚、巽辛、坎戊、离己、艮丙、兑丁），再按阴阳卦顺逆纳六辰，乾坤「分内外」以纳甲乙壬癸。

**边界**：为六爻占服务（世应、六亲、六神），是**离散的事件定位**工具，全无「气量」概念；其五行与八字五行同源而异用，直接混用即判据污染。

### 2.3 爻辰（郑玄）

**规则**：乾六爻纳子寅辰午申戌，坤六爻纳未巳卯丑亥酉，乾坤十二爻当十二辰，再配月、配律吕。

**边界**：机械对应；与十二消息卦配月构成两套并行且互斥的月—爻映射；今本依据多为清人辑佚复原，证据最弱。**离「推气」最远。**

## 三、十二消息卦与二气消长

| 卦 | 爻象 | 月建 | 农历月 | 二十四气 | 阳:阴 |
|---|---|---|---|---|---|

**结论一**：是。这是现存最早、最干净的「阴阳二气按月连续消长」离散采样：阳爻数即阳量，阴爻数即阴量，方向唯一、单调、可微（只差插值）。古法原型成立。

**结论二**：它给的是**天道常气**（年周期先验），不是**人命个体之气**。八字月令 = 个体出生时刻在这个年周期上截取的相位；消息卦 = 该相位的**先验期望值**。

**结论三**：与「月令定用忌」的关系是**先验与残差**，不是同一层。月令定「当令何气」（= 消息卦给出的基线），用忌定「命局对此气顺逆几何」（= 需日主强弱、寒暖燥湿、通关调候再判的残差）。故消息卦不能直接输出用忌，只能给出用忌判定的**参照系与归一化分母**。

## 四、可取的三条接口

**① 十二消息卦 → 月令二气配比的先验曲线。吸收「算法 + 数据结构」。**
产出 `prior(month) → {yangQty, yinQty, dYang/dMonth}`，取 12 锚点单调插值，锚点边界用**节气**而非月首（八字月柱本就以节气分界，与消息卦的月建分界天然对齐）。引擎实际值 = 先验 + 四柱偏移，残差大小直接可作「命局偏离常气」的度量。这是三条里唯一能进核心判据的。

**② 爻位当位/中正/应 → 结构合法性评分。吸收「结构」。**
它提供的是「位置—关系」约束范式：位之当否、是否得中、有无对应、比邻顺逆。可整体移植为八字宫位评分（宫位得位/失位、逢冲/逢合、透干/藏支）。**移植时必须去道德化**：原义的「当位=德称其位」是价值判断，引擎只保留位置关系与冲突计数。

**③ 错综互 → 多视角复核。吸收「算法」。**
错（全反）、综（倒置）、互（取中）是三种保信息的投影变换，天然适合做一致性校验：同一命局用正格/从格/调候三种视角各出一解，取交集为稳健结论，取差集为「需人工复核」标记。注意互卦只有 2-3-4/3-4-5 一种取法自洽，勿再派生。

三条均**不吸收**卦名、卦辞、爻辞的语义层——那属于解释学，不进判据。

## 五、明确不要吸收

1. **大衍揲蓍与变卦占断**：随机成卦，与「出生时刻定气」的确定性判据根本冲突；且不可复现。
2. **纳甲六亲 / 世应 / 六神**：另一套独立占断系统，其五行生克与八字同名异用，混入即双重计数、污染月令判据。**与命理判据冲突。**
3. **爻辰说**：机械配辰、与消息卦配月自相矛盾、辑佚复原不可靠，**不可证伪**。
4. **七十二候「一爻一候」的精细值**：历法漂移 + 强行 5 日等分，**过度诠释**；12 锚点已足够表达年周期，细到 72 只增噪声不增信息。
5. **图书学（河图洛书数、先天八卦数、元会运世）**：宋以后构造，非汉易象数底层；其「数」是宇宙论尺度，与个体命局无接口，**尺度不匹配 + 过度诠释**。
