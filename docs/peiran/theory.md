# 沛然堂线 · 纳音身命法理论 v1.0

> 本文件定义“沛然堂线”的核心逻辑、五维判断层、证据等级与扩展接口。  
> 结论先行：纳音适合做“身命/器识/取象/关系”层；在现有公共案例库上，纯纳音特征不足以稳定支撑五维 >70% 的硬分类。五维模块因此保留为“带证据与置信度的倾向判断”，不直接替客户下绝对结论。

## 一、核心命名

| 项 | 名称 |
|---|---|
| 业务线 | 沛然堂线（Peiran Line） |
| 逻辑核心 | 纳音身命法（Nayin Shen-Ming Method） |
| 数据书 | 《沛然堂纳音身命数据书》（Peiran Nayin Codex） |
| 五维判断层 | 纳音五维（盘层 / 学历 / 财富 / 情感 / 工作） |

## 二、三层结构

### 1. 体：身命结构

- 年柱纳音 = 身 / 本命 / 先天禀赋 / 祖业根基
- 月柱纳音 = 父母 / 少年
- 日柱纳音 = 自身 / 配偶 / 中年
- 时柱纳音 = 子女 / 晚年
- 胎元纳音 = 受胎环境 / 长辈缘分

### 2. 用：生克与气机

- 四柱纳音生克链：下生上、上生下、上克下、下克上
- 年命受生/受克/泄/制
- 刑冲害、三合局、纯旺/杂气、胎元关系
- 日柱纳音十二运（盲派口径：水申木亥金辰火卯土午）
- 大运/流年纳音生克 + 十二运评分

### 3. 象：六十甲子取象

- 三十组纳音质象（海中金、剑锋金、大林木、天河水……）
- 纳音喜忌（三命通会·释六十甲子）
- 兰台妙选象格（珠藏渊海、蚌珠照月、宝剑化青龙、水绕花堤等）
- 日柱纳音性情

## 三、五维判断层

| 维度 | 主特征 | 输出 | 当前证据强度 |
|---|---|---|---|
| 盘层 | 年命强弱、生克链、三合、纯旺、象格、胎元 | 高/中/低 + 证据 | 弱 |
| 学历 | 纳音学堂/词馆、文星、云龙风虎、源远流清 | 高/中/低 + 证据 | 中（标签不平衡） |
| 财富 | 顺克/逆克、年命受生/泄、三合、自生自旺、喜忌 | 高/中/低 + 证据 | 弱 |
| 情感 | 年日纳音生克、刑冲、纳音桃花 | 稳定/波动/未知 | 很弱（标签少） |
| 工作 | 纳音五行取象、剑锋/青龙/金马、生克链 | 体制/组织、企业/专业、个体/自由、学生/未工作 | 弱 |

每条输出结构：

```ts
interface DimVerdict {
  label: string;
  score: number;          // 0-100
  evidence: string[];     // 柱位 + 纳音 + 生克 + 出处
  confidence: 'high' | 'medium' | 'low';
}
```

## 四、证据等级与权重

| 等级 | 来源 | 建议权重 |
|---|---|---|
| ◎ 原典明断 | 三命通会、五行精纪、兰台妙选、星学大成 | 0.6 |
| ○ 原典取象 | 兰台妙选、三命通会取象 | 0.4 |
| △ 今人演绎 | 何锋、何重建、现代命理师 | 0.3 |
| ◇ 民间口诀 | 盲派年命法、纳音长生诀 | 0.2 |

冲突处理：

1. 年命 vs 日柱：双轨并行，分别回测，不混算。
2. 纳音长生 vs 正五行长生：锁定用途——旺衰用正五行，盲派断运用纳音长生，禁止跨表。
3. 象格 vs 正五行：象格只作取象/加分，不作硬断。
4. 纳音 vs 正五行冲突：正五行仲裁，纳音降为旁证。
5. 寿夭、子息数量、具体学历档位、具体职级：不硬断。

## 五、公共案例库回测结论（2026-11-03）

- 1180 例命海案例：财富 903、学历 1061、工作 1061、情感 854、盘层（出身代理）1061。
- 纯纳音五维规则：盘层 29.6%、学历 45.1%、财富 26.6%、工作 30.2%、情感 30.6%。
- 浅层决策树（70/30 切分）测试集：盘层 37.6%（baseline 52.8%）、学历 36.5%（baseline 46.3%）、财富 39.8%（baseline 48.7%）、工作 45.2%（baseline 51.4%）、情感 48.2%（baseline 52.9%）。
- 结论：**纯纳音特征没有稳定超过多数类基线**；>70% 五维硬分类在当前数据与特征下不可达。
- 59 条视频案例小样本：学历 72.7%（但 19/22 为高学历，类不平衡）、财富 52.4%、工作 55.6%、盘层 30.4%、情感仅 2 条标签。

详细数据见 [`validation.md`](./validation.md)。

## 六、下一步接口

### 1. 数据层接口

- `NayinEntry`：纳音名、五行、阴阳、干支、取象、喜忌、性情。
- 新数据书进入后，只改 `nayinData.ts`，引擎自动读取。

### 2. 特征层接口

- `PeiranAnalysis`：身命结构、生克链、身强弱、三合、刑冲、象格、大运/流年。
- `FiveDimensions`：五维 `DimVerdict`，带证据与置信度。
- 新规则以“特征→维度→方向→出处→权重”注册，不直接写死在 UI。

### 3. 回测层接口

- `scripts/peiran-backtest.mjs`：59 条视频案例。
- `scripts/peiran-backtest-minghai.mjs`：1180 条命海案例 + 浅层决策树实验。
- 每次改规则，至少跑这两个脚本，报告 baseline、exact accuracy、混淆矩阵。

### 4. 展示层接口

- 当前 `PeiranReport` 的 04 已展示盘层/学历/财富/工作四张“倾向”卡，同时显示置信度与证据链；不承诺硬分类准确率。
- 若后续准确率达标，可升级为更强的结论卡；当前仍以“倾向”表述。

## 七、结论

纳音不是“另一套子平”，而是一套以“身命/器识/取象”为核心的独立语言。它可以解释很多正五行看不到的气质、关系与象义，但当前公共案例库的标签质量与纳音特征强度，还不足以支撑五维硬分类。下一步应在“纳音取象 + 正五行底盘”的混合框架下继续回测，而不是继续给纯纳音加权。

## 八、社区补充（知乎/豆瓣正文提炼）

1. **见根才兑现**：年/日纳音五行在月/时支得长生、临官、帝旺，才算“有根”；无根则学历/财富/平台判断降权。
2. **同五行位次**：剑锋>沙中>白蜡>金箔>钗钏>海中；大海>天河>长流>大溪>井泉>涧下；位次只作平台/量级弱信号。
3. **纳音=处境**：正五行定“做什么”，纳音定“在什么环境做”；工作输出改为“行业方向 + 环境适配”，不直接断职级。
4. **时柱归宿**：时柱纳音为本行最强两组（壬戌癸亥、庚寅辛卯等）→ 晚发/转机标记。
5. **年运纳音**：流年纳音生年命为吉、克为凶；大运纳音逢墓/绝为蹇滞，长生/临官/帝旺为有力。
6. **情感桃花**：年/日纳音桃花 + 年日纳音生克 + 刑冲；只作情感活跃/波动提示，不直接断离婚或忠贞。

详见 [`community-sources.md`](./community-sources.md) 与 [`rules.md`](./rules.md#八社区补充规则知乎豆瓣正文提炼)。
