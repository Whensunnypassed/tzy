## 二、知乎：主要矛盾与不可靠点

1. **全盘否定派**（p/11308942950）：称纳音“无验证、谬论”，但无统计，且与《三命通会》《李虚中命书》《兰台妙选》原文冲突。
2. **象意→性格机械映射**（p/699380877、p/1991102730459161495）：海中金“城府深”、剑锋金“多名人”，多为文学附会，无命例。
3. **强弱排序自相矛盾**：p/336222993 金序为剑锋>沙中>白蜡>金箔>钗钏>海中；p/1991102730459161495 又标钗钏“阴强”、沙中“阴中”、金箔“阴弱”，两套标准混用。
4. **以纳音断寿夭**：多篇用“年纳音被克+年支刑→短寿”事后追认，违反“不判寿命”原则。
5. **起源七说互斥**：鬼谷子/东方朔、娄景、京房六十律、纳甲、天文历法、天干倒序、“我破解了”，说明底层无公认。

## 四、豆瓣：主要矛盾与不可靠点

1. **属相定纳音**：同属兔有土/金/水/火四纳音，属相不能定纳音。
2. **大海水咸不生木**：违水生木，也与“纳音生克可成立”冲突。
3. **“子平怎么用纳音就怎么用”**：年命 vs 日主、见根 vs 十神，非等价。
4. **纳音长生表混用**：note/823590975 的十二宫表与正五行长生、盲派口诀三套并存，不可跨表。
5. **实证神话**：note/812336832 “8条全应验”、橙猫/绿LED两天提分，无盲测；书评“吻合到疑非人造”是幸存者偏差。
6. **断寿元**：group/topic/139353090、note/823590975 含判寿，违反现代使用边界。

## 五、并入沛然堂线的增补规则

1. **见根规则**：年/日纳音五行在月支或时支得长生、临官、帝旺，才视为“能兑现”；无根则学历/财富/平台判断降权。
2. **位次规则**：同五行纳音按“剑锋>沙中>白蜡>金箔>钗钏>海中；大海>天河>长流>大溪>井泉>涧下；松柏>大林>杨柳>桑柘>石榴>平地；天上>霹雳>炉中>山下>山头>覆灯；大驿>路旁>沙中>城头>壁上>屋上”作平台/量级弱信号。
3. **处境规则**：正五行定“做什么”，纳音定“在什么环境做”；工作输出改为“行业方向 + 环境适配”，不再直接断职级。
4. **时柱归宿**：时柱纳音为本行最强两组（壬戌癸亥、庚寅辛卯、丙午丁未、戊子己丑、庚子辛丑等）→ 晚发/转机标记。
5. **大运/年运**：流年纳音生年命为吉、克为凶；大运纳音逢墓/绝为蹇滞；长生/临官/帝旺为有力。
6. **情感**：年/日纳音桃花 + 年日纳音生克 + 刑冲；不直接断离婚/忠贞。
7. **空亡**：六甲空亡只作“虚/未定”提示，不单独定吉凶。

## 六、证据分级与使用边界

- A/B 级规则可进“纳音旁证/软评分”；C 级只作取象/提示；D 级只作反证与边界提醒。
- 任何规则不得单独断寿夭、子息数量、具体学历档位、具体职级。
- 与正五行冲突时，正五行仲裁；纳音只解释“处境/气质/关系”。
