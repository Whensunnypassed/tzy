## 〇 体例

| 字段 | 含义 |
|---|---|
| 输入 | 这门用什么起算 |
| 判据 | 它凭什么下结论 |
| 输出 | 它最后给什么 |
| 可验证 | 可计算 / 部分可计算 / 不可验证 |
| 冲突 | 与哪派互斥，同一盘为何出相反结论 |
| 可借接口 | 若采用，只借哪一条；无则「不进判据」 |

**登记约定（我自定，不是任何门派或权威的规定）**：① 一格只许一家的方法；②「不可验证」的照样收，但标出来；③ 借用必须写明借的哪一条接口。

## 三 使用规则

1. **查**：按门派看它凭什么判、能不能验、可借哪条。
2. **标**：任何输出必须标「出自哪一派、哪一条判据」；一页里出现两派判据而没标接口，视为混算。
3. **借**：只走「可借接口」列写明的入口，借来的量不得单独升级为吉凶判据。
4. **拒**：「不可验证」的只作语料与象意，不进任何计算。
