## 二、设计方案

### A. 结果区栅格：三栏化，把右栏变成「批注栏」
- 结果区宽度 `max-w-6xl` → **`max-w-[1440px]`**（lg+ 生效；输入表单仍 `max-w-xl` 不变）。
- lg+ 栅格 → **`grid-cols-[172px_minmax(0,1fr)_320px]`**：
  - 左 172：编号导航（sticky，收窄）。
  - 中 `minmax(0,1fr)`：主栏，只放**结论**。
  - 右 320：**批注栏**（原 180px 目录升级而来；目录移到主栏顶部横向编号条或左栏底部）。
- 窄屏（<lg）：右批注栏折叠到对应模块正文下方（见 B）。

### B. 模块内「正文 + 批注」两列（论文批注式）
每个版块外壳改为 `lg:grid-cols-[minmax(0,1fr)_300px]`：
- 左列 = 该模块**结论正文**（四柱表 / 用忌两栏 / 大运表 …）。
- 右列 = 该模块**旁注**：细规线 + `label-mono` 元信息 + 依据/口径/明细，随模块对齐（天然对齐，无需跨模块坐标同步）。
- 这样批注落在原「右侧空白」处，主栏视觉宽度保持稳定阅读尺度，且**减少 60% 的纵向滚动**。
- 窄屏：批注列改为正文下方可折叠块，默认收起。

### C. 全局视图开关：`结论视图 / 全量视图`
主栏顶部加分段开关，默认 **结论视图**。结论视图下默认隐藏（并入折叠「依据（展开）」或批注栏）：
- 评分方法论、图例、口径说明、本盘定局横幅、五行块说明
- 逐字喜忌明细（保留结论行）、条件字明细
- 司令真神、春秋月关键因子、干支自合标记、生克权流转
- 六亲换太极、五行取象、地支作用规则、古法旁证区（十干定性/天干四冲·地支六破/驿马/形干同性重克）
- 命局函数曲线、四柱限段、太极二气配比、土专区

「全量视图」= 现状全显，供研读/校对；两视图共用同一 DOM，仅切换折叠态。

### D. 模块内 2-up 并排（削减纵向长度）
lg 下：03 月气子模块、06 年月太极四子模块、07 象意三子模块 → 两列并排；01 四柱本身已横向。

## 三、十二长生环序重做

**现状**：10 张卡片 grid（`min-w-[620px]` + `overflow-x-auto`，见 [L2641-L2662](file:///d:/tzy/tzy-remote/src/pages/BaZiAnalyzerPage/BaZiAnalyzerPage.tsx#L2641-L2662)）——丢失「环」与「波动」几何语义。

**推荐：圆环 + 半径映射 power（先出静图确认再实现）**
- 12 个长生阶段沿圆周顺时针排布（**绝为起点**，与 `CHANG_SHENG_STATES` 真源一致）。
- 每个天干按其月令落点落在对应阶段角度上；**径向长度 = power**（正→向外、负→向内），圆心为 0。
- 环内/环心标注月令与日主；原局所透之干以实心块高亮（沿用现有 `inChart` 语义）。
- 峰在「帝旺」、谷在「绝」——波动一眼可读，替换卡片 grid。

**备选：弧形波动曲线**（与「命局函数曲线」风格统一）
- 横轴 = 12 阶段，纵轴 = power，画一条正弦状弧线，10 个天干为弧上的点。
- 优点：与 02·A 函数曲线同范式；缺点：「环序」语义弱于圆环。

**实现**：新增纯函数旁证组件 `ChangShengRingChart.tsx`（SVG，消费既有 `changShengRing.entries/order`，不改引擎），替换现有卡片 grid；文字结论 `verdict` 保留。
