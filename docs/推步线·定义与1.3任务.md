## 〇 一句话

推步线把「月令太极二气配比」提为唯一判据，用李虚中的三元结构（干禄 / 支命 / 身）承载，用周易十二消息卦作先验、六壬月将作相位、六爻月建日辰作触发，**只判气机，不判事件**，每一层都要能被回测推翻。

它不是第四套命理，是同一套引擎的第二个口径。

## 一 定义

### 1.1 定义句

> **推步线：以月令太极二气之消长为唯一判据，以三元结构承载，以可回测为验的命理判断线。**
> 推步者，步算天时以知来也。

拆成三句必须同时成立的话：

1. **唯一判据**：任何吉凶结论都能反查到「该命例在该月令下的阳量 / 阴量 / 斜率」这一个数；查不到，就不是推步线的结论。
2. **结构承载**：判据只负责「气够不够」，三元负责「气落在哪」——干禄（名禄贵权）、支命（金珠积富）、身（材能器识与人伦亲属）。身不产气，只承载。
3. **可回测**：每一层都要能独立关掉、独立打开，用同一批命例比较「加这一层之后一致率有没有上升」；不上升就删。

### 1.2 名出何典

「推步」是古天文历法术语：《后汉书·律历志》《晋书·律历志》一类史志以「推步」指步算天度、推定节气与合朔，与「占候」（观云气、占星变、断吉凶）并列而分途。取此名有三层意思：

- **算，不是断**：它算气机的存量与走向，不直接下「吉／凶」的断语——断语要等回测给出置信度。
- **步，是过程**：一步一步推，可复核、可重算，结论依赖输入不依赖师承。
- **与「占候」划界**：神煞、卦辞、天将吉凶那一类「观象取断」的东西，明确不在本线。

【待考】史志中「推步」与「占候」分列的具体篇目与句读，待查《后汉书·律历志》《晋书·律历志》原书后补精确引文；不影响命名，仅影响文献脚注。

### 1.4 边界：不做什么

以下八条写进代码注释与线头声明，作为防偏离的硬约束：

1. 不搬纳音本体（纳音只作「身」的标签，不产气）。
2. 不收神煞（天乙、文昌、桃花一类一律不进判据）。
3. 不判寿夭（健康只作倾向提示）。
4. 不输出无置信度的事件断语（婚姻「必离」、事业「必贵」不写）。
5. 不让先验数据直接出结论（消息卦只作归一化分母）。
6. 不让标记层进总分（旬空、月破、伏吟、返吟只标窗口）。
7. 不混用两套时间标尺（节气月令 vs 中气月将，见 C6）。
8. 不同时使用「身」（固定）与「用神」（随问而变）作为判据（见 C8）。

## 三 四术互参：它们其实是同一套语法

把四份简报摊开看，四术表面各说各话，底下是同一套四件套。

### 3.1 共同语法

| 构件 | 周易 | 李虚中 | 六壬 | 六爻 | 推步线取法 |
|---|---|---|---|---|---|
| **锚点**（谁被判断） | 卦爻位（本卦/变卦） | 三元（干禄/支命/身） | 四课 + 三传 | 世应 + 用神 | 取「三元」作固定锚点；弃随问用神 |
| **状态位**（临时性质） | 当位/中正/应 | 无（以旺衰代替） | 伏吟/返吟/空亡/墓 | 旬空/月破/暗动/回头生克 | 只作修饰层，不进总分 |
| **时间标尺** | 节气 + 候（六日七分） | 胎月日时 + 限运 | 中气换月将 | 月建（常）+ 日辰（变） | 节气定月令，中气只给相位 k |
| **关系算子** | 爻位相应 | 干支配十神与刑冲合害 | k = 月将 − 月建 | 生克冲合 | 只引八字层已算好的结果，不重算 |

**一句总结**：四术都按「谁 / 什么状态 / 什么时候 / 和谁什么关系」四件事组织信息；推步线把第一件固定、第二件降级为标记、第三件拆成两个标尺、第四件复用。

### 3.2 交叉印证：八条可以借鉴的深层同构

1. **十二节点是公共网格**。周易十二消息卦（子复→亥坤）与六壬十二月将（亥将→戌将）都是 12 个时间节点，**但一个是节气、一个是中气**。同一网格、两把尺——这句话本身就是 C6 冲突的由来，也是先验曲线能与相位算子对齐的原因。
2. **「常 + 变」两层层层重现**。消息卦＝年周期常气，月令相位＝个体采样；月建＝常，日辰＝变；天地盘＝常，四课三传＝变；主本＝常，限运＝变。**四术一致的时间结构就是「常数层定基调 + 变动层定触发」**——这正是推步线五层模型里 L0/L1 与 L3/L4 的分野。
3. **主从二元结构可统一，语义不可通约**。世应（我/他）、四课体用（事/身）、年本日主（本/末）、本卦变卦（静/动）都是「一个主锚 + 一个从锚」。可以统一成 `AnchorPair{primary, secondary}` 的数据结构，但四家的主从含义完全不同，只能共享形状，不能共享解释。
4. **「身」与「用神」是两种不同性质的锚**。李虚中的「身」是固定维度（这个人的器识与人伦），六爻的「用神」是随问而变（问考试取父母、问财取妻财）。**固定锚可回测，随机锚不可回测**——推步线只收前者，这是 C8 的裁决依据，也是「不做占卜工具」的技术理由。
5. **状态位是「修饰层」，四术都同意它不该进总分**。旬空、月破、伏吟、返吟、当位失位，本质都是「此刻这个爻/柱处于非常态」，只影响窗口松紧，不影响底色。推步线把它们统一成 `Trigger[]`，带 `window` 与 `confidence`，绝不并入二气比。
6. **参数端点在各家都表现为「全对称 / 全破」**。六壬 k=0 伏吟、k=6 返吟；周易乾纯阳、坤纯阴。这不是巧合：循环结构在 0 与 n/2 处必然出现对称。可以作为 `prior.ts` 与 `phase.ts` 的边界测试用例（12 个锚点里第 1 与第 7 个必须最「纯」）。
7. **装饰层的共同特征：可无限增补、不可证伪**。神煞、六神、天将、卦辞、纳音吉凶断语，全都是「加一条不冲突、删一条也不损失」的附录。历史把它筛掉了（见 `docs/命理源流考.md` 上编「文本可靠性判定表」）——推步线统一标 `NO_JUDGEMENT`，只作阅读材料。
8. **「纳音身」与「六亲」是同一件事的两种锚**。李虚中把「人伦亲属」挂在纳音，六爻把「六亲」挂在卦宫五行，子平把「六亲」挂在十神。三套锚互不换算；推步线只取十神（社会关系读数），纳音身只保留材能器识与人伦描述文本，不参与计算（C4）。

### 4.3 闸门与验收标准

**P1（先验闸门，T2 结束）**
- 12 个锚点值与 `MONTH_QI_EXPANDED` 的 `guaXiang` 一一对应；
- 节气边界（立春 / 惊蛰 / 清明 / 立夏 / 芒种 / 小暑 / 立秋 / 白露 / 寒露 / 立冬 / 大雪 / 小寒）各测一例；
- `复→乾` 斜率恒正、`姤→坤` 斜率恒负；
- 第 1 与第 7 锚点（复 / 姤）进出对称。

**P2（判据闸门，T7 结束）**
- `YONG_JI_SOURCE='taiji'` 下，同一命例四次运行结果一致（无随机性、无随问变量）；
- 8 例验证集逐条给出「二气配比 → 用忌」的反查链；
- 回退开关可用：切回 `binary` 时输出与 1.2.0 完全一致（黄金测试）。

**P3（增量闸门，T8 结束）**
- 对 N 例（先 8 例，后扩 50–100）跑四版本：二气 / +先验 / +结构 / +触发，比较一致率；
- 任一层增量 ≤ 0 → 该层删除或降级为展示层；

## 六 跨时代考验：往前推几百年，能算对吗

> 这一节回答「这个经得住考验吗，如果我向前推，用几百年前的，我们能算对吗」。
> 结论先行：**天文层能算对，判读层不能承诺；历史样本的正确用途是证伪，不是背书。**

### 6.1 先拆三层，因为「算对」在三层里不是一件事

| 层 | 问的问题 | 能否客观验证 | 跨时代 |
|---|---|---|---|
| 天文层（排盘） | 四柱、节气、真太阳时、大运起运对不对 | 能（对 JPL DE441 / 历史节气表） | ✅ |
| 结构层（二气 / 用忌 / 格局） | 判据推出来的气机结构对不对 | 理论内自洽，样本外不可证 | ⚠️ 只在「天道常气」尺度成立 |
| 内容层（富贵形态、事件、六亲） | 「贵」具体长什么样、「富」长什么样 | 不能 | ❌ 语义随朝代漂移 |

### 6.2 天文层：经得起

- 节气由太阳视黄经定义，回归年尺度极稳；VSOP87 / DE441 可回推数千年，本项目星历对 JPL 误差 ≤3 角分。
- 干支纪日连续未断，儒略日可精确定位古今任一日期。
- 古代没有标准时，地方平时 + 经度修正算真太阳时反而是本义；也没有 1986–1991 夏令时那样的坑。
- 岁差不影响节气：黄经以分点为起算，进动已含在定义里。
- 唯一真实风险是**古历 ≠ 今历**（平气 / 定气、历元不同），把古人记的日期换算到公历可能差一天；落在节气边界上的样本会翻盘，回测时应把「节气前后 ±1 天」的命例单列为不确定样本。

### 6.3 判读层：不能承诺，四条硬理由

1. **样本偏差**：几百年前有确切生辰的多是名人，生辰常按「吉时」择录，生平记载带立场；用这种样本回测，必然高估。
2. **语义漂移**：「名禄贵权」「金珠积富」在明清指科举功名、田产、宗族，在今天是职位、资本、流量。判据能给方向，内容要翻译，而翻译没有依据。
3. **时间精度**：古代只记时辰（两小时一档），时柱有相当概率是错的；时柱直接进二气配比，判据被污染。
4. **未验证的放大**：判读层从未被任何独立样本验证过（见 `docs/命理源流考.md` 的偏离机制设想），跨时代验证只会把这个「未验证」放大，不会解决它。

### 6.4 但推步线比多数流派更抗时间

判据是天文量（阳量 / 阴量 / 斜率），不是民俗量。神煞、纳音吉凶、卦辞、天将吉凶都绑定具体社会与文本传统，换朝代必失真；二气消长是年周期函数，换朝代照旧。这是它值得做、而神煞不值得做的原因。

### 6.5 正确用法：历史样本压测排盘，不背书判读

- **能做**：节气边界、闰月、无时区、无夏令时、时辰模糊——检验排盘鲁棒性，这类测试可 100% 客观。
- **不能做**：拿名人命例证明「断得准」。
- **若要盲测，按这个设计**：
  1. 取 20 例有确切生辰与生平的古人（明清为主，避开传说人物）；
  2. 先盲排，只输出 3 条可证伪判断（如 30–45 岁是否有职位 / 身份变动、是否离乡、是否丧偶）；
  3. 再对答案，统计命中率与随机基线；
  4. 预期：天文层 100%，判读层接近随机或略高。**显著高于随机才值得继续**；不高，就把产品定位写成「结构解读工具」，而不是预测工具。
- 报告写 `docs/tuibu-backtest.md`（本地，不入库）。

### 6.6 一句回答

往前推几百年，**排盘能算对，判读不敢保证**。但正因为它不敢保证，才要用几百年前的样本去证伪，而不是拿几百年后的名气去背书。

## 七 天文层误差修正与验收线（2026-11-04 主人定标）

### 7.1 误差来源与可修性

| 误差源 | 量级 | 能否修 | 修法 |
|---|---|---|---|
| 古历 / 今历（平气定气、闰月、历元） | ≤1 天 | ✅ | 节气与朔望全部按天文重算（已有 VSOP87），不查万年历表 |
| 时辰模糊（两小时一档） | 0–2 h | ✅ 部分 | 时辰建模为区间，边界样本双算，输出两个时柱 |
| 真太阳时（均时差、经度） | <4 min | ✅ | 公式已有；古地名需坐标映射 |
| 起运（三日折一年） | ±数月 | ✅ | 用精确到时辰的起运修正 |
| 城市库只覆盖今城 | — | ✅ | 建古地名→今坐标映射表 |

结论：**天文层的误差全部可量化、可修正**；修完之后只剩「记录本身错」这一类不可修误差——时辰按吉时择录、生辰为攀附伪造。这一类只能靠样本筛选规避，不能靠算法。

### 7.2 修正方案（三条）

1. **天文朔望替代查表**：节气计算已有 `solarTermsCalc`；新增 `lunarAstro.ts`，用 VSOP87 的新月（朔）时刻反推农历日期，摆脱「1900 年后才准」的查表局限。
2. **边界样本双算**：节气前后 ±1 天、时辰前后 ±30 分钟、闰月首尾日，标 `boundary: true`，同时输出上下界两组四柱；主报告用主值，回测时两组都算，命中任一即记命中并单列。
3. **时辰区间建模**：时柱不确定时按 2 个候选各算一次二气配比，输出区间而不是单值。

### 7.3 验收线（主人定标 2026-11-04）

- 古代样本，**排除边界样本后：60% 合格，70–80% 优秀**。
- 统计纪律（必须事先登记，否则结果不算数）：
  - 样本量：先 20 例 × 3 条可证伪判断 = 60 个判定；若要分辨 60% 与 70%，需扩到 50 例 = 150 个判定。
  - 命中定义写死为二元（例：「30–45 岁是否换过职位」= 有 / 无），不许事后改口径。
  - 基线对照：用同代同阶层人群的该事件基础发生率做基线，不用 50% 硬套。
  - 报告 Wilson 95% 区间：n=60 时 60% 的区间约 [47%, 72%]——所以「60% 合格」适合作为最低门槛，不适合作为结论。
  - 排除规则在开盲**之前**冻结，开盲后不得换样本。
- 一句话：60% 作为合格线我认；但报告必须带置信区间，不让合格线变成无法复核的口号。

### 7.4 新增任务

- **T10 古历与边界模块**（2d）：`lunarAstro.ts`、`boundary.ts`、古地名坐标映射。验收：1900 年前的日期可算，节气边界样本能双算出两组四柱。
- **T11 盲测协议与登记表**（1d）：`docs/tuibu-blindtest.md`（本地，不入库），含样本表、预注册规则、编码者与仲裁流程。验收：规则冻结后才开盲。

## 八 表达层：先定「读什么」，再定「怎么画」

> **8.0 纠偏记录**：本节初稿写的是「干支为坐标、二气为读数」，被主人指出本末倒置——读数根本不用干支，却让干支当表达的主语。现改为从读数反推表达。原判断「保留干支是为了可对照古籍」也站不住：新路线对外交流本来就要转译。干支剩下的硬理由只有两个——**地址**（每柱唯一标识）与**与历史案例对齐**（核验用，不是表达用）。

### 8.1 先列读数

推步线读出来的只有六样东西：

| 编号 | 读数 | 性质 |
|---|---|---|
| R1 | 十二个月的阳量 / 阴量场 | 连续、年周期 |
| R2 | 四柱作为四个采样点的贡献分解（本气 / 藏干 / 月令） | 离散、可加 |
| R3 | 实算与先验常气的偏离（残差） | 有正负 |
| R4 | 斜率与转向点（阳进 / 阳退的拐点） | 方向 |
| R5 | 状态标记（旬空、月破、伏吟、返吟、边界样本） | 布尔/枚举 |
| R6 | 置信区间（样本量、时辰模糊、古历差带来的误差带） | 区间 |

### 8.2 读数 → 表达

| 读数 | 怎么画 | 为什么 |
|---|---|---|
| R1 | 12 格横向时间带 + 面积图（阳在轴上、阴在轴下），出生点一条竖线 | 连续量就用连续轴，不用字 |
| R2 | 四根堆叠柱，每柱分「本气 / 藏干 / 月令」三段 | 分解要能一眼看出主次 |
| R3 | 零轴上的残差条，正负分色 | 「偏离」是一个差，正负必须看得见 |
| R4 | 斜率箭头 + 拐点圆点 | 趋势是方向，不是数值 |
| R5 | 角标、虚线框、窗口带（不进面积） | 状态是「此刻特殊」，不占读数面积 |
| R6 | 半透明误差带覆盖 R1 | 不确定要画出来，不能藏 |

### 8.3 从六壬 / 六爻借四个母题

1. **两层盘**（六壬天地盘 → 常气层 / 个体层）：外环是十二消息卦的常气，内环是十二月的月建，两环夹角就是 k——k=0 两环对齐（伏吟），k=6 两环对冲（返吟）。R1 与 R5 因此能画在同一张图上。
2. **动爻与传链**（六爻动爻、六壬三传 → 大运流年的「动」）：把大运、流年画成时间带上的「动」标记与箭头链，只标「何时动」，不标「动得好不好」。
3. **双钟**（六爻月建 / 日辰 → 慢 / 快双尺度）：报告顶部两个小表——慢钟=节气月（大运流年），快钟=流月流日（触发窗口）。
4. **世应**（六爻主从 → 本 / 用两栏）：报告首屏给「本（三元）」与「用（当前大运气）」两栏对照，主从关系一眼可见。

### 8.4 干支的正确位置

- 只剩两个用途：**地址**（数据关联、深链接）与**核验**（与古籍、历史案例对齐时转译）。
- 画法：等宽小字，挂在柱顶或节点下方；不参与主视觉，不承载读数的量。
- 报告保留一行「四柱」纯文本作索引，正文的图不依赖它。

### 8.5 与希腊线的视觉区分

- 希腊线是黄道圆盘 + 行星 + 相位弦；推步线用**方形网格 + 横向时间带**（可把两层环简化为上下两行 12 格色带，对齐即伏吟），不画圆盘，避免两条线视觉撞车，也符合瑞士网格。
- 两条线共用排盘，但图形语言必须不同：一个是「天球」，一个是「气机带」。

### 8.6 数据关联

`chart` 仍是 `FourPillars`（地址）；读数层是 `LayerValue[]`，以 `pillarId` 关联，形如 `{ pillarId, yang, yin, source, confidence }`。UI 只画图与标签，**禁止在 UI 层重算任何气量**。
