## 〇 一句话

推步线把「月令太极二气配比」提为唯一判据，用李虚中的三元结构（干禄 / 支命 / 身）承载，用周易十二消息卦作先验、六壬月将作相位、六爻月建日辰作触发，**只判气机，不判事件**，每一层都要能被回测推翻。

它不是第四套命理，是同一套引擎的第二个口径。

## 一 定义

### 1.1 定义句

> **推步线：以月令太极二气之消长为唯一判据，以三元结构承载，以可回测为验的命理判断线。**
> 推步者，步算天时以知来也。

拆成三句必须同时成立的话：

1. **唯一判据**：任何吉凶结论都能反查到「该命例在该月令下的阳量 / 阴量 / 斜率」这一个数；查不到，就不是推步线的结论。
2. **结构承载**：判据只负责「气够不够」，三元负责「气落在哪」——干禄（名禄贵权）、支命（金珠积富）、身（材能器识与人伦亲属）。身不产气，只承载。
3. **可回测**：每一层都要能独立关掉、独立打开，用同一批命例比较「加这一层之后一致率有没有上升」；不上升就删。

### 1.2 名出何典

「推步」是古天文历法术语：《后汉书·律历志》《晋书·律历志》一类史志以「推步」指步算天度、推定节气与合朔，与「占候」（观云气、占星变、断吉凶）并列而分途。取此名有三层意思：

- **算，不是断**：它算气机的存量与走向，不直接下「吉／凶」的断语——断语要等回测给出置信度。
- **步，是过程**：一步一步推，可复核、可重算，结论依赖输入不依赖师承。
- **与「占候」划界**：神煞、卦辞、天将吉凶那一类「观象取断」的东西，明确不在本线。

【待考】史志中「推步」与「占候」分列的具体篇目与句读，待查《后汉书·律历志》《晋书·律历志》原书后补精确引文；不影响命名，仅影响文献脚注。

### 1.4 边界：不做什么

1. 不搬纳音本体（纳音只作「身」的标签，不产气）。
2. 不收神煞（天乙、文昌、桃花一类一律不进判据）。
3. 不判寿夭（健康只作倾向提示）。
4. 不输出无置信度的事件断语（婚姻「必离」、事业「必贵」不写）。

6. 不让标记层进总分（旬空、月破、伏吟、返吟只标窗口）。
7. 不混用两套时间标尺（节气月令 vs 中气月将，见 C6）。
8. 不同时使用「身」（固定）与「用神」（随问而变）作为判据（见 C8）。

## 三 四术互参：它们其实是同一套语法

把四份简报摊开看，四术表面各说各话，底下是同一套四件套。

### 3.1 共同语法

| 构件 | 周易 | 李虚中 | 六壬 | 六爻 | 推步线取法 |
|---|---|---|---|---|---|
| **锚点**（谁被判断） | 卦爻位（本卦/变卦） | 三元（干禄/支命/身） | 四课 + 三传 | 世应 + 用神 | 取「三元」作固定锚点；弃随问用神 |
| **状态位**（临时性质） | 当位/中正/应 | 无（以旺衰代替） | 伏吟/返吟/空亡/墓 | 旬空/月破/暗动/回头生克 | 只作修饰层，不进总分 |
| **时间标尺** | 节气 + 候（六日七分） | 胎月日时 + 限运 | 中气换月将 | 月建（常）+ 日辰（变） | 节气定月令，中气只给相位 k |
| **关系算子** | 爻位相应 | 干支配十神与刑冲合害 | k = 月将 − 月建 | 生克冲合 | 只引八字层已算好的结果，不重算 |

**一句总结**：四术都按「谁 / 什么状态 / 什么时候 / 和谁什么关系」四件事组织信息；推步线把第一件固定、第二件降级为标记、第三件拆成两个标尺、第四件复用。

### 3.2 交叉印证：八条可以借鉴的深层同构

1. **十二节点是公共网格**。周易十二消息卦（子复→亥坤）与六壬十二月将（亥将→戌将）都是 12 个时间节点，**但一个是节气、一个是中气**。同一网格、两把尺——这句话本身就是 C6 冲突的由来，也是先验曲线能与相位算子对齐的原因。
2. **「常 + 变」两层层层重现**。消息卦＝年周期常气，月令相位＝个体采样；月建＝常，日辰＝变；天地盘＝常，四课三传＝变；主本＝常，限运＝变。**四术一致的时间结构就是「常数层定基调 + 变动层定触发」**——这正是推步线五层模型里 L0/L1 与 L3/L4 的分野。
3. **主从二元结构可统一，语义不可通约**。世应（我/他）、四课体用（事/身）、年本日主（本/末）、本卦变卦（静/动）都是「一个主锚 + 一个从锚」。可以统一成 `AnchorPair{primary, secondary}` 的数据结构，但四家的主从含义完全不同，只能共享形状，不能共享解释。
4. **「身」与「用神」是两种不同性质的锚**。李虚中的「身」是固定维度（这个人的器识与人伦），六爻的「用神」是随问而变（问考试取父母、问财取妻财）。**固定锚可回测，随机锚不可回测**——推步线只收前者，这是 C8 的裁决依据，也是「不做占卜工具」的技术理由。
5. **状态位是「修饰层」，四术都同意它不该进总分**。旬空、月破、伏吟、返吟、当位失位，本质都是「此刻这个爻/柱处于非常态」，只影响窗口松紧，不影响底色。推步线把它们统一成 `Trigger[]`，带 `window` 与 `confidence`，绝不并入二气比。
6. **参数端点在各家都表现为「全对称 / 全破」**。六壬 k=0 伏吟、k=6 返吟；周易乾纯阳、坤纯阴。这不是巧合：循环结构在 0 与 n/2 处必然出现对称。可以作为 `prior.ts` 与 `phase.ts` 的边界测试用例（12 个锚点里第 1 与第 7 个必须最「纯」）。
7. **装饰层的共同特征：可无限增补、不可证伪**。神煞、六神、天将、卦辞、纳音吉凶断语，全都是「加一条不冲突、删一条也不损失」的附录。历史把它筛掉了（见 `docs/命理源流考.md` 上编「文本可靠性判定表」）——推步线统一标 `NO_JUDGEMENT`，只作阅读材料。
8. **「纳音身」与「六亲」是同一件事的两种锚**。李虚中把「人伦亲属」挂在纳音，六爻把「六亲」挂在卦宫五行，子平把「六亲」挂在十神。三套锚互不换算；推步线只取十神（社会关系读数），纳音身只保留材能器识与人伦描述文本，不参与计算（C4）。

## 六 跨时代考验：往前推几百年，能算对吗

> 这一节回答「这个经得住考验吗，如果我向前推，用几百年前的，我们能算对吗」。
> 结论先行：**天文层能算对，判读层不能承诺；历史样本的正确用途是证伪，不是背书。**

### 6.1 先拆三层，因为「算对」在三层里不是一件事

| 层 | 问的问题 | 能否客观验证 | 跨时代 |
|---|---|---|---|
| 天文层（排盘） | 四柱、节气、真太阳时、大运起运对不对 | 能（对 JPL DE441 / 历史节气表） | ✅ |
| 结构层（二气 / 用忌 / 格局） | 判据推出来的气机结构对不对 | 理论内自洽，样本外不可证 | ⚠️ 只在「天道常气」尺度成立 |
| 内容层（富贵形态、事件、六亲） | 「贵」具体长什么样、「富」长什么样 | 不能 | ❌ 语义随朝代漂移 |

### 6.2 天文层：经得起

- 节气由太阳视黄经定义，回归年尺度极稳；VSOP87 / DE441 可回推数千年，本项目星历对 JPL 误差 ≤3 角分。
- 干支纪日连续未断，儒略日可精确定位古今任一日期。
- 古代没有标准时，地方平时 + 经度修正算真太阳时反而是本义；也没有 1986–1991 夏令时那样的坑。
- 岁差不影响节气：黄经以分点为起算，进动已含在定义里。
- 唯一真实风险是**古历 ≠ 今历**（平气 / 定气、历元不同），把古人记的日期换算到公历可能差一天；落在节气边界上的样本会翻盘，回测时应把「节气前后 ±1 天」的命例单列为不确定样本。

### 6.3 判读层：不能承诺，四条硬理由

1. **样本偏差**：几百年前有确切生辰的多是名人，生辰常按「吉时」择录，生平记载带立场；用这种样本回测，必然高估。
2. **语义漂移**：「名禄贵权」「金珠积富」在明清指科举功名、田产、宗族，在今天是职位、资本、流量。判据能给方向，内容要翻译，而翻译没有依据。
3. **时间精度**：古代只记时辰（两小时一档），时柱有相当概率是错的；时柱直接进二气配比，判据被污染。
4. **未验证的放大**：判读层从未被任何独立样本验证过（见 `docs/命理源流考.md` 的偏离机制设想），跨时代验证只会把这个「未验证」放大，不会解决它。

### 6.4 但推步线比多数流派更抗时间

判据是天文量（阳量 / 阴量 / 斜率），不是民俗量。神煞、纳音吉凶、卦辞、天将吉凶都绑定具体社会与文本传统，换朝代必失真；二气消长是年周期函数，换朝代照旧。这是它值得做、而神煞不值得做的原因。

### 6.5 正确用法：历史样本压测排盘，不背书判读

- **能做**：节气边界、闰月、无时区、无夏令时、时辰模糊——检验排盘鲁棒性，这类测试可 100% 客观。
- **不能做**：拿名人命例证明「断得准」。
- **若要盲测，按这个设计**：
  1. 取 20 例有确切生辰与生平的古人（明清为主，避开传说人物）；
  2. 先盲排，只输出 3 条可证伪判断（如 30–45 岁是否有职位 / 身份变动、是否离乡、是否丧偶）；
  3. 再对答案，统计命中率与随机基线；
  4. 预期：天文层 100%，判读层接近随机或略高。**显著高于随机才值得继续**；不高，就把产品定位写成「结构解读工具」，而不是预测工具。
- 报告写 `docs/tuibu-backtest.md`（本地，不入库）。

### 6.6 一句回答

往前推几百年，**排盘能算对，判读不敢保证**。但正因为它不敢保证，才要用几百年前的样本去证伪，而不是拿几百年后的名气去背书。

## 七 天文层误差修正与验收线（2026-11-04 主人定标）

### 7.1 误差来源与可修性

| 误差源 | 量级 | 能否修 | 修法 |
|---|---|---|---|
| 古历 / 今历（平气定气、闰月、历元） | ≤1 天 | ✅ | 节气与朔望全部按天文重算（已有 VSOP87），不查万年历表 |
| 时辰模糊（两小时一档） | 0–2 h | ✅ 部分 | 时辰建模为区间，边界样本双算，输出两个时柱 |
| 真太阳时（均时差、经度） | <4 min | ✅ | 公式已有；古地名需坐标映射 |
| 起运（三日折一年） | ±数月 | ✅ | 用精确到时辰的起运修正 |
| 城市库只覆盖今城 | — | ✅ | 建古地名→今坐标映射表 |

结论：**天文层的误差全部可量化、可修正**；修完之后只剩「记录本身错」这一类不可修误差——时辰按吉时择录、生辰为攀附伪造。这一类只能靠样本筛选规避，不能靠算法。

### 7.2 修正方案（三条）

1. **天文朔望替代查表**：节气计算已有 `solarTermsCalc`；新增 `lunarAstro.ts`，用 VSOP87 的新月（朔）时刻反推农历日期，摆脱「1900 年后才准」的查表局限。
2. **边界样本双算**：节气前后 ±1 天、时辰前后 ±30 分钟、闰月首尾日，标 `boundary: true`，同时输出上下界两组四柱；主报告用主值，回测时两组都算，命中任一即记命中并单列。
3. **时辰区间建模**：时柱不确定时按 2 个候选各算一次二气配比，输出区间而不是单值。

### 7.3 验收线（主人定标 2026-11-04）

- 古代样本，**排除边界样本后：60% 合格，70–80% 优秀**。
- 统计纪律（必须事先登记，否则结果不算数）：
  - 样本量：先 20 例 × 3 条可证伪判断 = 60 个判定；若要分辨 60% 与 70%，需扩到 50 例 = 150 个判定。
  - 命中定义写死为二元（例：「30–45 岁是否换过职位」= 有 / 无），不许事后改口径。
  - 基线对照：用同代同阶层人群的该事件基础发生率做基线，不用 50% 硬套。
  - 报告 Wilson 95% 区间：n=60 时 60% 的区间约 [47%, 72%]——所以「60% 合格」适合作为最低门槛，不适合作为结论。
  - 排除规则在开盲**之前**冻结，开盲后不得换样本。
- 一句话：60% 作为合格线我认；但报告必须带置信区间，不让合格线变成无法复核的口号。

### 7.4 新增任务

- **T10 古历与边界模块**（2d）：`lunarAstro.ts`、`boundary.ts`、古地名坐标映射。验收：1900 年前的日期可算，节气边界样本能双算出两组四柱。
- **T11 盲测协议与登记表**（1d）：`docs/tuibu-blindtest.md`（本地，不入库），含样本表、预注册规则、编码者与仲裁流程。验收：规则冻结后才开盲。

## 八 表达层：先定「读什么」，再定「怎么画」

> **8.0 纠偏记录**：本节初稿写的是「干支为坐标、二气为读数」，被主人指出本末倒置——读数根本不用干支，却让干支当表达的主语。现改为从读数反推表达。原判断「保留干支是为了可对照古籍」也站不住：新路线对外交流本来就要转译。干支剩下的硬理由只有两个——**地址**（每柱唯一标识）与**与历史案例对齐**（核验用，不是表达用）。

### 8.1 先列读数

推步线读出来的只有六样东西：

| 编号 | 读数 | 性质 |
|---|---|---|
| R1 | 十二个月的阳量 / 阴量场 | 连续、年周期 |
| R2 | 四柱作为四个采样点的贡献分解（本气 / 藏干 / 月令） | 离散、可加 |
| R3 | 实算与先验常气的偏离（残差） | 有正负 |
| R4 | 斜率与转向点（阳进 / 阳退的拐点） | 方向 |
| R5 | 状态标记（旬空、月破、伏吟、返吟、边界样本） | 布尔/枚举 |
| R6 | 置信区间（样本量、时辰模糊、古历差带来的误差带） | 区间 |

### 8.2 读数 → 表达

| 读数 | 怎么画 | 为什么 |
|---|---|---|
| R1 | 12 格横向时间带 + 面积图（阳在轴上、阴在轴下），出生点一条竖线 | 连续量就用连续轴，不用字 |
| R2 | 四根堆叠柱，每柱分「本气 / 藏干 / 月令」三段 | 分解要能一眼看出主次 |
| R3 | 零轴上的残差条，正负分色 | 「偏离」是一个差，正负必须看得见 |
| R4 | 斜率箭头 + 拐点圆点 | 趋势是方向，不是数值 |
| R5 | 角标、虚线框、窗口带（不进面积） | 状态是「此刻特殊」，不占读数面积 |
| R6 | 半透明误差带覆盖 R1 | 不确定要画出来，不能藏 |

### 8.3 从六壬 / 六爻借四个母题

1. **两层盘**（六壬天地盘 → 常气层 / 个体层）：外环是十二消息卦的常气，内环是十二月的月建，两环夹角就是 k——k=0 两环对齐（伏吟），k=6 两环对冲（返吟）。R1 与 R5 因此能画在同一张图上。
2. **动爻与传链**（六爻动爻、六壬三传 → 大运流年的「动」）：把大运、流年画成时间带上的「动」标记与箭头链，只标「何时动」，不标「动得好不好」。
3. **双钟**（六爻月建 / 日辰 → 慢 / 快双尺度）：报告顶部两个小表——慢钟=节气月（大运流年），快钟=流月流日（触发窗口）。
4. **世应**（六爻主从 → 本 / 用两栏）：报告首屏给「本（三元）」与「用（当前大运气）」两栏对照，主从关系一眼可见。

### 8.4 干支的正确位置

- 只剩两个用途：**地址**（数据关联、深链接）与**核验**（与古籍、历史案例对齐时转译）。
- 画法：等宽小字，挂在柱顶或节点下方；不参与主视觉，不承载读数的量。
- 报告保留一行「四柱」纯文本作索引，正文的图不依赖它。

### 8.5 与希腊线的视觉区分

- 希腊线是黄道圆盘 + 行星 + 相位弦；推步线用**方形网格 + 横向时间带**（可把两层环简化为上下两行 12 格色带，对齐即伏吟），不画圆盘，避免两条线视觉撞车，也符合瑞士网格。
- 两条线共用排盘，但图形语言必须不同：一个是「天球」，一个是「气机带」。

### 8.6 数据关联

`chart` 仍是 `FourPillars`（地址）；读数层是 `LayerValue[]`，以 `pillarId` 关联，形如 `{ pillarId, yang, yin, source, confidence }`。UI 只画图与标签，**禁止在 UI 层重算任何气量**。

## 十 判据自立：推步线自有 L3（qiJudge）

> 2026-11-04 晚，主人拍板：「断语和判断逻辑，既然自立门户，就自己想出来一套。」于是 L3 不再调用阴阳线的 `computeTaiJiQi`，改为 `src/analysis/tuibu/qiJudge.ts`。

### 10.1 为什么另起

- 阴阳线的判据是「月令太极二气配比 → 用阴/用阳 → 五行用忌」，断语也长在那套语汇里。推步线若沿用，等于换皮。
- 推步线要的输出不是「用哪个五行」，而是「气机偏在哪、离常气多远、该泄还是该补」——这是另一套可独立标定、独立回测的量。

### 10.2 自有量：气偏 Q

| 量 | 定义 |
|---|---|
| 干气 | 天干五行在月令的旺相休囚死（旺 +1.0 / 相 +0.6 / 休 0 / 囚 −0.5 / 死 −0.9），阳干取正、阴干取负 |
| 支气 | 地支藏干按 1.0 / 0.7·0.3 / 0.6·0.3·0.1 份额加权，再乘 0.75（支为地，承而不显） |
| 柱权 | 年 1.0 / 月 1.6 / 日 1.2 / 时 0.8 |
| 气偏 Q | 四柱（干 + 支）× 柱权之和 ÷ 理论上限，钳制到 [−1, +1] |
| 先验 P | 消息卦阳爻数：(阳量 − 3) / 3 |
| 残差 Δ | Q − P，正值＝比常气更阳，负值＝更阴 |
| 顺逆 | 残差与先验同号＝顺，反号＝逆，\|Δ\|<0.05＝平 |
| 态势 | Q ≥ +0.45 阳过 / ≥ +0.15 偏阳 / ≤ −0.45 阴过 / ≤ −0.15 偏阴 / 其余中和 |
| 调候 | 阳过·偏阳 → 泄；阴过·偏阴 → 补；中和 → 守 |

### 10.3 断语怎么生成

断语由 L3 自己拼四句，不取任何外部 verdict：

1. 月建、消息卦名、先验阳阴与基线；
2. 气偏、残差、顺逆、态势；
3. 调候方向与理由；
4. 三元承载（胎元 / 干禄 / 支命 / 身）＋「判据只走气机，不点五行用忌」。

示例（2000-12-10 子月，庚辰 / 戊子 / 壬寅 / 庚子）：

> 子月消息卦「复」：先验阳 1/6、阴 5/6，基线 −0.67。
> 命局四柱气偏 −0.22，残差 +0.44，逆先验；态势：偏阴。
> 调候取「补」：阴气偏重，宜温补——以升、动、暖为度，不必大攻。
> 三元承载：胎元 己卯、干禄 庚申、戊巳、壬亥、支命 癸、身 寅·自身配偶；判据只走气机，不点五行用忌。

### 10.4 边界（写死）

- 不读 `src/analysis/yinyang/*` 的任何函数；推步线页面只 import `common` 的类型与 `tuibu/` 自身模块。
- 不输出「用阴 / 用阳」，不输出五行用忌；调候只给 泄 / 补 / 守。
- 权重与阈值是**推步线自定参数**，与方案 B 无关，可单独标定、单独回测。
- 先验只做分母与残差参照；L3 不出具体事件，不出寿夭。

### 10.5 验证

- `scripts/tuibu-prior-check.mjs` 增判据 6 项：全阳四柱 Q > 0、全阴 Q < 全阳、Q ∈ [−1, 1]、Δ = Q − P、全阴不出「阳过」、断语含卦名；连同动态层与四域共 **67 项**（§11、§12）。
- `npx tsc -p tsconfig.app.json --noEmit` exit 0。

## 十一 动态层：大运与流年并入同一公式（qiFlow）

> 2026-11-04 深夜，主人问：「盘上运/岁只是位置标记，把它们真正并入 Q 的公式还没写，要不要接着做？」——做。

### 11.1 一句话

判断不另起一套：把大运柱、流年柱当成**追加的两柱**，塞进与命局完全相同的 `qiOf`，得到三个点位。

```
命局 Q0 = qiOf(月建, 四柱)
大运 Q1 = qiOf(月建, 四柱 + 大运柱 × 1.4)
流年 Q2 = qiOf(月建, 四柱 + 大运柱 × 1.4 + 流年柱 × 1.0)
```

`Δ运 = Q1 − Q0`、`Δ年 = Q2 − Q1`、`Δ总 = Q2 − Q0`。跨过态势带（±0.15 / ±0.45）另记 `crossed`。

### 11.2 权重与理由

- **大运 1.4**：十年之纲，比单柱重、比月令轻；不压过命局四柱（合计 4.6）。
- **流年 1.0**：一年之用，与年柱同权，供「岁运同参」。
- 运与年同样受月令旺衰约束——它们不是另加的气，是同一套五行在月令下的读数。

### 11.3 边界

- 只回答「气机往哪边推、推了多少、有没有跨带」，不判具体事件、不判寿夭。
- 流年取 `recentLiuNian` 中当年条目；缺条目就只算到运，不补默认值。
- L4 冲合窗口仍只标时间，不并入 Q。

### 11.4 可视化

推步盘右栏「气机走向 / Q FLOW」三条 bullet：命局 / 大运 / 流年，各自在 −1…+1 轴上标点位，右侧给 Q、Δ、态势。流年点用朱红。三点若挤在一起，说明这十年、这一年气机没怎么动；点拉开，才是「转」。

示例（庚辰 / 戊子 / 壬寅 / 庚子，2026 年）：

| 点位 | 干支 | Q | Δ | 态势 |
|---|---|---|---|---|
| 命局 | 本命四柱 | −0.22 | +0.00 | 偏阴 |
| 大运 | 庚寅 | −0.17 | +0.06 | 偏阴 |
| 流年 | 丙午 | −0.17 | +0.00 | 偏阴 |

合参：偏阴，宜「补」——气机基本没动，这十年是平推，不是转机。

### 11.5 验证

`scripts/tuibu-prior-check.mjs` 增 7 项：三点位、命局点等于静盘 Q、总偏移等于末点减首点、阳运高于阴运、缺流年只给两点、断语含「流年」「合参」。合计 **61 项**，`tsc` exit 0（四域另 6 项见 §12.10）。

## 十二 作用与四域：禄 / 财 / 身 / 亲

> 2026-11-04 深夜，主人问：大运流年怎么作用、好坏没表现出来、妻财子禄学业事业怎么算、当下该走什么方向。这一节把这条链写死。

### 12.1 古籍依据（不借子平十神）

李虚中《命书》卷中，三元各主一事，原文：

> 「干主名禄贵权，为衣食受用之基；支主金珠积富，为得失荣枯之本；纳音主材能器识，为人伦亲属之宗。」

同一卷：

> 「旺衰之理，审量生克；轻重之名，须识向背。」

本线取「向背」二字做判法：不判吉凶，只判**顺不顺、向还是背**。四域不取十神，只取三元与宫位。

### 12.2 四域定义

| 域 | 记量 | 读什么 | 出处 |
|---|---|---|---|
| 禄 | 四柱天干之气 | 名禄贵权 · 事业与位置 | 「干主名禄贵权」 |
| 财 | 四柱地支藏干之气 | 金珠积富 · 资源与获得 | 「支主金珠积富」 |
| 身 | 日柱之气（本线以日柱承身） | 材能器识 · 学业与所长 | 「纳音主材能器识」（本线不搬纳音，暂以日柱承之，标 low） |
| 亲 | 日支（配偶）+ 时柱（子女） | 妻与子 · 宫位关系 | 「为人伦亲属之宗」+ 四柱宫位 |

### 12.3 合身度

每个域算出气偏 q（与 Q 同一套 `phaseScore`），以「身」为锚：

```
fit = 1 − |q_域 − q_身| / 2      ∈ [0, 1]
```

身与域同向 → fit 接近 1；反向 → 接近 0。这不是「命好不好」，是**结构与自身气机顺不顺**。

### 12.4 好作用 / 坏作用

运、年分别再加一柱（运 1.4、年 1.0）重算四域，看 fit 的变化：

```
Δ运 = fit(命+运) − fit(命)
Δ年 = fit(命+运+年) − fit(命+运)

Δ ≥ +0.02 → 好作用（向）
Δ ≤ −0.02 → 坏作用（背）
其余       → 平
```

所以「大运流年的作用」不再是一句吉凶，而是四个域各自被推近还是推远。可能财变好、禄变坏——这就是「好作用坏作用」的具体位置。

### 12.5 当下方向

- 取 fit 最低的域 → **补**；
- 取 fit 最高的域 → **依**；
- 身是锚，不参与补/依的选择。

示例（庚辰 / 戊子 / 壬寅 / 庚子，大运庚寅、流年丙午）：

| 域 | 气偏 | 合身 | 大运 | 流年 |
|---|---|---|---|---|
| 禄 | +0.09 | 0.67 | −0.01 平 | −0.07 坏 |
| 财 | −0.64 | 0.56 | +0.08 好 | +0.09 好 |
| 身 | +0.59 | 1.00 | 0.00 平 | 0.00 平 |
| 亲 | −0.19 | 0.61 | 0.00 平 | 0.00 平 |

读法：财域离身最远（0.56），是当前最背的域 → **先补财**；禄域合身最高（0.67）→ **可依禄**。大运与流年对财都是好作用，说明资源方向在回暖，但底子仍偏。

### 12.6 两轴不混

- **Q**（气机：偏阴 / 偏阳 / 中和）判「该补还是该泄」，管整体态势；
- **四域 fit** 判「哪一块顺、哪一块背」，管结构向背。

两者可以相反：整体偏阴要「补」，但财域正在变好——不矛盾，一个说气，一个说向。

### 12.7 边界

- 不判具体事件（不写「今年升职」），不判寿夭，不判富贵等级；
- 合身度是结构读数，不是命运打分；
- 亲域只到「妻与子」的宫位关系，不推具体人；
- 四域参数（权重、阈值）是推步线自定，可单独标定。

### 12.8 验证

`scripts/tuibu-prior-check.mjs` 增四域 6 项：四域齐、fit ∈ [0,1]、身域 fit=1、身不作补依、好作用对应正增量、无运年时无作用。合计 **67 项**，`tsc` exit 0。

是结构描述，不是成就预测。

## 十四 串盘：从盘到判断的完整链（逻辑，未落地）

### 14.1 先自检：现在能不能判？

把现有零件串一遍，诚实结论：**不能判人，只能描述。**

| 零件 | 能给什么 | 缺什么 |
|---|---|---|
| Q | 偏阴/偏阳一个数 | 没有「事」，且运年只把它挪 0.05–0.1，落不到态势阈值上 |
| 四域 fit | 禄财身亲顺不顺 | fit 只说「与身同向」，不说「这一步能不能成」 |
| Δfit | 好/坏作用 | 是加权平均，运年两柱把分母拉大，作用被稀释 |
| 名位 | 立不立得住 | 只是静态结论，不参与运年判断 |
| 纳音 | 器识一句 | 象，不入数 |
| trigger | 冲合窗口 | 只标时间，不判轻重 |
| 盘 | 12 格 + 当前运/岁两个标签 | 没有时间轴：八步大运、五年流年无处可看 |

一句话：**它现在能说「你偏阴、财域最背」，说不出「你这一步运做什么会顺、哪年会动」——而后者才叫判盘。**

### 14.2 判定必须有四要素

| 要素 | 问什么 | 对应层 |
|---|---|---|
| 体 | 本命是什么结构（阴阳、四域、名位） | Q / 四域 / 名位 |
| 用 | 运、年**作用在谁身上**、是助还是夺 | 待建：生克作用律 |
| 应 | 什么时候动（冲合刑害） | trigger |
| 事 | 落哪个域（禄/财/身/亲） | 四域 |

缺「用」这一层，运年就只能是旁注——这正是主人指出的问题。

### 14.3 作用律（待定稿）

不用十神，用五行生克（李虚中：「旺衰之理，审量生克」）：

**干与干**（运干/年干 × 命局四干）：

| 关系 | 判 | 分 |
|---|---|---|
| 运干生命干 | 助 | +1 |
| 运干与命干同 | 比助 | +0.6 |
| 运干克命干 | 抑 | −1 |
| 命干生运干 | 泄 | −0.5 |
| 命干克运干 | 耗（我克它，得财） | +0.3 |

**支与支**（运支/年支 × 命局四支）：

| 关系 | 判 | 用法 |
|---|---|---|
| 六冲 | 动 | 应期标记，扣域分 0.3 |
| 六合 | 牵 | 应期标记，域分 +0.2 |
| 三合半合 | 聚 | 域分 +0.2 |
| 相刑/相害 | 扰 | 应期标记，扣 0.2 |
| 伏吟（同支） | 复 | 标记，不加减 |

**归域**：干作用于禄（四干）、支作用于财（四支）、日支与时的支作用于亲；身取日柱，由日干与日支两条各半。

**域作用分** = Σ(每柱 关系分 × 柱权) / Σ柱权，得 −1…+1。

| 分 | 判 |
|---|---|
| ≥ +0.35 | 得 |
| +0.15…+0.34 | 微得 |
| −0.14…+0.14 | 平 |
| −0.34…−0.15 | 微失 |
| ≤ −0.35 | 失 |

**与 fit 的分工**：fit 说「这域与你顺不顺」（静态），作用分说「这一步运年是助它还是夺它」（动态）。两个都高才是「此时可做」；fit 低而作用分高，是「补得动」；fit 高而作用分低，是「守」。

### 14.4 判定五步

1. 读体：Q、四域 fit、名位、纳音象。
2. 读用：当前大运与流年，按 14.3 出四域作用分。
3. 读应：trigger 的冲合刑害落在哪个支哪一柱。
4. 合判：fit × 作用分 → 「可做 / 可守 / 勿动 / 补而待」。
5. 给方向：补最背之域、依最合之域，并写清「这一步」与「下一步」。

| 能 | 器识、名位、身域 | 纳音、名位、四域 fit |
| 势 | 四域强度与运年作用 | domainFlow |

判读只到「倾向」，不出「定论」；置信度恒标「低」，等 8 例校准后再升级。

### 15.2 学业

```text
capacity = min(1, |q_身| / 0.6)        // 身域 fit 恒为 1，是锚，不能当器量
score = 0.45 × capacity + 0.30 × (名 ≥ 0.15) + 0.25 × (气势 == 中和)
高 ≥ 0.72；中 ≥ 0.50；低 < 0.50
```

三条依据都印在页面上，不藏在黑箱里：身域（读书是不是这把器）、名位（学历显不显）、气势（坐不坐得住）。

### 15.3 学科

五行气量份额（干按柱权、支按藏干份额与 0.75 支系数），取最旺一行定学科大类；气势偏阴取静、偏阳取动，在类象表内重排优先级。

| 五行 | 学科/行业类象 |
|---|---|
| 木 | 文史哲、教育、生物农林、设计出版、法律 |
| 火 | 电子能源、传媒艺术、化工资讯、餐饮、表演 |
| 土 | 建筑地产、农林牧、管理、中介仓储、地理 |
| 金 | 机械制造、金融、法律军警、外科医学、五金 |
| 水 | 信息计算、贸易物流、医药心理、海洋水利、金融 |

### 15.4 职业

```text
强度 = |q域| × fit域
职业 = 强度最高的那一域
```

- 禄 = 体制/管理/名位；财 = 经商/资源/市场；身 = 技术/研究/技艺；亲 = 服务/教育/医疗。
- 名位不实而禄最高 → 附「可做事，不宜争名位」；财域合身偏低 → 附「宜资源整合，不宜重仓压货」。

### 15.5 现在能说到什么程度

示例盘（庚辰/戊子/壬寅/庚子，乾造）的判读：

- 学历「中」（0.68）：身域 1.00 能学，但名位俱弱，学历不显。
- 学科「水 63%」：信息计算 / 医药心理 / 贸易物流。
- 职业「技术 / 研究 / 技艺」：身域最强，靠本事与作品。
- 一句话：先把一门手艺/学问坐实，再谈位置。

这是**结构倾向**，不是事实断言；反例应当能推翻它，而不是被它解释掉。

### 15.6 边界

- 不判寿夭、不判具体事件、不判收入数字。
- 职业/学科表是类象归并，不是统计；同一五行可以横跨几个行业。
- 后续校准：8 例先算一致率，再谈阈值；低于 60% 就改表或改权重，不硬圆。
